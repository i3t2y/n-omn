### §2.2 我侧 real_context=200000 消费链字节级一致核 (file:line)
- **我侧写入径**: init-nim-keys.sh:893 直写 SQLite `model_context_overrides (provider='nvidia', real_context=200000, source='init')`。
- **3.8.48 消费链** (modelCapabilities.ts:513-526):
  ```ts
  export function getModelContextLimit(providerOrInput, modelId?) {
    const resolved = ... getResolvedModelCapabilities(...);
    // Feature 5004: a persisted override (operator-set or auto-discovered) wins over the
    // static catalog / models.dev sync. `getResolvedModelCapabilities` stays override-free
    // so the reconciler can compare the catalog value against provider-declared windows.
    const override = getModelContextOverride(resolved.provider, resolved.model);
    return override ?? resolved.contextWindow;
  }
  ```
- **3.8.43 同消费链** (modelCapabilities.ts:436-449): 四行**字节级一致** — getResolvedModelCapabilities → getModelContextOverride → `override ?? resolved.contextWindow`。Feature 5004 注释字字同。
- **判**: 我侧 real_context=200000 走 `getModelContextOverride` 表径, **与 3.8.48 新加的 authoritative static map / max_token override / maxInputTokens 新链正交** (override 优先级 = persisted 表 > static catalog > models.dev sync, 新链仅作用于无 persisted override 的 fallback 路径)。我侧 nvidia 有 persisted override, 永远走第一优先径, 新机制不触及。
