### **本轮相对上一版的核心修正**

本次不是功能堆叠,而是删除所有未经 3.8.43 实例证实的"聪明自动化",依据官方 `RESILIENCE_GUIDE.md`(v3.8.40,与 3.8.43 同族)的证伪结论:

第一,彻底删除 `providerBreaker` / `connectionCooldown` 猜测字段。官方文档证实熔断与冷却阈值是内置常量(API-key 档:7 次降级 / 12 次熔断 / 30s 重置),且熔断**仅对 408/500/502/503/504 触发,不含 429**——429 归 Connection Cooldown(尊重 `Retry-After`)管。因此 GLM-5.2 那段 `providerBreaker:{failureThreshold:3}` 方向虽对但字段名是错的,应删除。

第二,限流由 Gate 自行强制执行共享预算,不依赖 OmniRoute 内部 Request Queue API(其 Schema 未完全锁定)。Gate 用内存令牌桶实现 RPM 滑动窗口 + 并发计数 + 间隔 pacing 三层整形。

第三,删除 `NIM_SCALE_WITH_KEYS`。即便默认设为 0,它仍会给维护者留下"Key 可线性扩容"的错误暗示。固定预算 28 RPM / 1 并发 / 2200ms,多 Key 仅作冗余与健康轮换。

第四,Context Override 改为纯观测模式,只输出 `context-recommendations.ndjson` 报告,不自动 SQL 兜底、不自动 PATCH。失败判定只认 `413` 及带 context/token/length 文本的 400/422。

第五,彻底移除 Relay 三节点架构,回归原生 NIM 直连:`Agent → Gate → OmniRoute 3.8.43 → NVIDIA 官方端点`。

## **文件二:entrypoint.sh**

核心改动——entrypoint 保持 PID 1,显式监督 OmniRoute、Gate、Litestream 三进程;任一核心进程退出则容器退出交由编排层重启;健康等待用绝对时间戳截止;Litestream 仅本地无库时才恢复并做 `quick_check`。

```sh
#!/bin/sh
set -eu

DATA_DIR="${DATA_DIR:-/data}"
DB_PATH="$DATA_DIR/storage.sqlite"
OMNIROUTE_PORT="${OMNIROUTE_PORT:-20128}"
EXPOSED_PORT="${EXPOSED_PORT:-7860}"
READY_TIMEOUT_SECONDS="${READY_TIMEOUT_SECONDS:-180}"
EXPECTED_OR_VERSION="${EXPECTED_OR_VERSION:-3.8.43}"

OR_PID=
GATE_PID=
LS_PID=

mkdir -p "$DATA_DIR"
chmod 700 "$DATA_DIR" 2>/dev/null || true

has_r2_credentials() {
  [ -n "${R2_ACCESS_KEY_ID:-}" ]   && \
  [ -n "${R2_SECRET_ACCESS_KEY:-}" ] && \
  [ -n "${R2_ACCOUNT_ID:-}" ]     && \
  [ -n "${R2_BUCKET:-}" ]
}

shutdown() {
  trap - INT TERM EXIT
  for pid in "$GATE_PID" "$OR_PID" "$LS_PID"; do
    [ -n "$pid" ] || continue
    kill -TERM "$pid" 2>/dev/null || true
  done
  sleep 3
  for pid in "$GATE_PID" "$OR_PID" "$LS_PID"; do
    [ -n "$pid" ] || continue
    kill -KILL "$pid" 2>/dev/null || true
  done
  wait 2>/dev/null || true
}
trap shutdown INT TERM EXIT

# ── Litestream restore：本地有库跳过；无库才恢复 + quick_check ──
if [ -s "$DB_PATH" ]; then
  echo '[entrypoint] local database exists; restore skipped.'
elif has_r2_credentials; then
  echo '[entrypoint] local database absent; attempting restore.'
  rm -f "$DB_PATH-wal" "$DB_PATH-shm" "$DB_PATH-journal"
  if litestream restore -config /litestream.yml -if-replica-exists "$DB_PATH"; then
    if [ -s "$DB_PATH" ]; then
      check="$(sqlite3 "$DB_PATH" 'PRAGMA quick_check;' 2>/dev/null || true)"
      if [ "$check" != 'ok' ]; then
        echo '[entrypoint] FATAL: restored database failed quick_check.' >&2
        exit 1
      fi
      echo '[entrypoint] database restored and verified.'
    else
      echo '[entrypoint] no remote replica found; OmniRoute will initialize a new database.'
    fi
  else
    echo '[entrypoint] FATAL: Litestream restore failed.' >&2
    exit 1
  fi
else
  echo '[entrypoint] no local database and no complete R2 configuration.'
fi

# ── 启动 OmniRoute ──
# 保持基础镜像原始入口命令；只替换其周围的恢复/等待/监督逻辑。
PORT="$OMNIROUTE_PORT" \
DATA_DIR="$DATA_DIR" \
REQUIRE_API_KEY=true \
HOSTNAME=127.0.0.1 \
NODE_OPTIONS="--max-old-space-size=4096" \
DISABLE_SQLITE_AUTO_BACKUP=true \
PROVIDER_LIMITS_SYNC_INTERVAL_MINUTES=1440 \
CALL_LOGS_TABLE_MAX_ROWS="${CALL_LOGS_TABLE_MAX_ROWS:-100000}" \
PROXY_LOGS_TABLE_MAX_ROWS="${PROXY_LOGS_TABLE_MAX_ROWS:-100000}" \
JWT_SECRET="$JWT_SECRET" \
API_KEY_SECRET="$API_KEY_SECRET" \
OMNIROUTE_API_KEY="$OMNIROUTE_API_KEY" \
INITIAL_PASSWORD="$INITIAL_PASSWORD" \
node /app/server.js --log &
OR_PID=$!
echo "[entrypoint] OmniRoute PID=$OR_PID"

# ── 健康等待：绝对时间戳截止，避免调度暂停导致计数器失准 ──
deadline=$(( $(date +%s) + READY_TIMEOUT_SECONDS ))
while :; do
  if ! kill -0 "$OR_PID" 2>/dev/null; then
    echo '[entrypoint] FATAL: OmniRoute exited during startup.' >&2
    wait "$OR_PID" || true
    exit 1
  fi
  if curl -fsS --connect-timeout 2 --max-time 5 \
      "http://127.0.0.1:${OMNIROUTE_PORT}/api/monitoring/health" >/dev/null 2>&1; then
    echo '[entrypoint] OmniRoute is ready.'
    break
  fi
  if [ "$(date +%s)" -ge "$deadline" ]; then
    echo '[entrypoint] FATAL: OmniRoute readiness timeout.' >&2
    exit 1
  fi
  sleep 2
done

# ── 版本护栏（只告警不中断；STRICT_VERSION_LOCK=1 则退出）──
_OR_VER=$(curl -fsS "http://127.0.0.1:${OMNIROUTE_PORT}/api/monitoring/health" 2>/dev/null \
  | jq -r '.version // "unknown"' 2>/dev/null || echo "unknown")
echo "[entrypoint] base version: $_OR_VER (expected $EXPECTED_OR_VERSION)"
if [ "$_OR_VER" != "$EXPECTED_OR_VERSION" ] && [ "$_OR_VER" != "unknown" ]; then
  echo "[entrypoint] WARN: version($_OR_VER) != expected($EXPECTED_OR_VERSION) — possible FROM drift."
  [ "${STRICT_VERSION_LOCK:-0}" = "1" ] && { echo '[entrypoint] FATAL: STRICT_VERSION_LOCK=1, aborting.' >&2; exit 1; }
fi

# ── NIM 初始化（同步执行；失败按策略处理）──
if [ -x /entrypoint-init-nim.sh ]; then
  if ! /entrypoint-init-nim.sh; then
    if [ "${INIT_FAILURE_FATAL:-1}" = "1" ]; then
      echo '[entrypoint] FATAL: NIM initialization failed.' >&2
      exit 1
    fi
    echo '[entrypoint] WARN: NIM initialization failed; continuing with persisted configuration.'
  fi
fi

# ── Litestream 复制（重要但非核心：退出告警，不拖垮容器）──
if has_r2_credentials; then
  litestream replicate -config /litestream.yml &
  LS_PID=$!
  echo "[entrypoint] Litestream PID=$LS_PID"
fi

# ── Gate ──
node /gate/gate.js &
GATE_PID=$!
echo "[entrypoint] Gate PID=$GATE_PID"

# ── 监督循环：核心进程死亡则容器退出 ──
while :; do
  if ! kill -0 "$OR_PID" 2>/dev/null; then
    echo '[entrypoint] FATAL: OmniRoute exited.' >&2
    wait "$OR_PID" || true
    exit 1
  fi
  if ! kill -0 "$GATE_PID" 2>/dev/null; then
    echo '[entrypoint] FATAL: Gate exited.' >&2
    wait "$GATE_PID" || true
    exit 1
  fi
  if [ -n "$LS_PID" ] && ! kill -0 "$LS_PID" 2>/dev/null; then
    if [ "${LITESTREAM_REQUIRED:-0}" = "1" ]; then
      echo '[entrypoint] FATAL: Litestream exited.' >&2
      wait "$LS_PID" || true
      exit 1
    fi
    echo '[entrypoint] WARN: Litestream exited; replication disabled until restart.'
    wait "$LS_PID" || true
    LS_PID=
  fi
  sleep 5
done
```

## **文件三:gate.js**

核心改动——Gate 自行执行共享预算(内存令牌桶:RPM 滑动窗口 + 并发计数 + 间隔 pacing),不依赖 OmniRoute 内部 API;路径用正则挂载避免 `pathRewrite` 版本差异;PSK 用 `crypto.timingSafeEqual`;`/v1/search/analytics` 单独 404。

```js
'use strict';

const crypto = require('crypto');
const express = require('express');
const { createProxyMiddleware } = require('http-proxy-middleware');

function positiveInt(value, fallback) {
  const parsed = Number.parseInt(String(value ?? ''), 10);
  return Number.isSafeInteger(parsed) && parsed > 0 ? parsed : fallback;
}

const exposedPort    = positiveInt(process.env.EXPOSED_PORT, 7860);
const omniPort       = positiveInt(process.env.OMNIROUTE_PORT, 20128);
const rpm            = positiveInt(process.env.NIM_SHARED_RPM, 28);
const maxConcurrent  = positiveInt(process.env.NIM_MAX_CONCURRENT, 1);
const minIntervalMs  = positiveInt(process.env.NIM_MIN_INTERVAL_MS, 2200);

const expectedPSK = process.env.GATE_PSK || process.env.INTERNAL_PSK || '';
const target = `http://127.0.0.1:${omniPort}`;

let OR_API_KEY = (process.env.OMNIROUTE_API_KEY || '').trim();
if (!OR_API_KEY) {
  try { OR_API_KEY = require('fs').readFileSync('/data/.or-api-key', 'utf8').trim(); }
  catch (e) { if (e.code !== 'ENOENT') console.error('[gate] WARN read key failed:', e.message); }
}

if (!expectedPSK) { console.error('[gate] FATAL: GATE_PSK not set.'); process.exit(1); }
if (!OR_API_KEY)  { console.error('[gate] FATAL: No OR_API_KEY (env nor file).'); process.exit(1); }

const app = express();

// ── 共享预算：内存令牌桶（RPM 滑动窗口 + 并发 + 间隔）──
let active = 0;
let lastStartedAt = 0;
const starts = [];

function secureEqual(left, right) {
  const a = Buffer.from(String(left || ''), 'utf8');
  const b = Buffer.from(String(right || ''), 'utf8');
  if (a.length !== b.length || a.length === 0) return false;
  return crypto.timingSafeEqual(a, b);
}

function suppliedKey(req) {
  const authorization = req.get('authorization') || '';
  if (/^Bearer\s+/i.test(authorization)) {
    return authorization.replace(/^Bearer\s+/i, '').trim();
  }
  return (req.get('x-api-key') || '').trim();
}

function authenticate(req, res, next) {
  if (!secureEqual(suppliedKey(req), expectedPSK)) {
    return res.status(401).json({ error: 'unauthorized' });
  }
  next();
}

function admit(req, res, next) {
  const now = Date.now();
  const minuteAgo = now - 60_000;
  while (starts.length && starts[0] <= minuteAgo) starts.shift();

  if (active >= maxConcurrent) {
    res.set('Retry-After', '2');
    return res.status(429).json({ error: 'gateway_concurrency_limit' });
  }
  if (starts.length >= rpm) {
    const retrySeconds = Math.max(1, Math.ceil((starts[0] + 60_000 - now) / 1000));
    res.set('Retry-After', String(retrySeconds));
    return res.status(429).json({ error: 'gateway_rpm_limit' });
  }
  const elapsed = now - lastStartedAt;
  if (elapsed < minIntervalMs) {
    const retrySeconds = Math.max(1, Math.ceil((minIntervalMs - elapsed) / 1000));
    res.set('Retry-After', String(retrySeconds));
    return res.status(429).json({ error: 'gateway_pacing_limit' });
  }

  active += 1;
  lastStartedAt = now;
  starts.push(now);

  let released = false;
  const release = () => {
    if (released) return;
    released = true;
    active = Math.max(0, active - 1);
  };
  res.once('finish', release);
  res.once('close', release);
  next();
}

// PSK → 真实 OR_API_KEY 替换
function rekey(req, _res, next) {
  req.headers.authorization = `Bearer ${OR_API_KEY}`;
  next();
}

app.disable('x-powered-by');

// ── 健康检查（公开）──
app.get('/healthz', async (_req, res) => {
  const controller = new AbortController();
  const timer = setTimeout(() => controller.abort(), 4000);
  try {
    const upstream = await fetch(`${target}/api/monitoring/health`, { signal: controller.signal });
    if (!upstream.ok) return res.status(503).json({ status: 'upstream_unhealthy' });
    return res.status(200).json({ status: 'ok' });
  } catch {
    return res.status(503).json({ status: 'upstream_unreachable' });
  } finally {
    clearTimeout(timer);
  }
});

const proxy = createProxyMiddleware({
  target,
  changeOrigin: false,
  xfwd: false,
  ws: false,
  timeout: 0,
  proxyTimeout: 0,
  on: {
    error(_error, _req, res) {
      if (!res.headersSent) res.writeHead(502, { 'content-type': 'application/json' });
      res.end(JSON.stringify({ error: 'upstream_unavailable' }));
    }
  }
});

// 仅放行 /v1 与 /v1/*：正则挂载，避免 pathRewrite 版本差异
app.use(/^\/v1(?:\/|$)/, authenticate, admit, rekey, proxy);

// 其余路径一律 404（含 Dashboard、管理 API、/v1/search/analytics）
app.use((_req, res) => res.status(404).json({ error: 'not_found' }));

app.listen(exposedPort, '0.0.0.0', () => {
  console.log(
    `[gate] listening on ${exposedPort}; target=${target}; ` +
    `rpm=${rpm}; concurrent=${maxConcurrent}; interval=${minIntervalMs}ms`
  );
});
```

> 部署后用 `curl /v1/models` 验证正则挂载的转发路径无 `/v1/v1` 或缺段。内存限流适合 HF 单容器;多实例需共享计数(如 Redis),本版未实现。

```bash
NIM_FAST_MODELS=(   "deepseek-ai/deepseek-v4-flash" "meta/llama-3.3-70b-instruct" "google/gemma-4-31b-it" )
NIM_CODEX_MODELS=(  "deepseek-ai/deepseek-v4-pro" "openai/gpt-oss-120b" "z-ai/glm-5.2" )

build_all_models() {
  printf '%s\n' "${NIM_POOL_MODELS[@]}" "${NIM_STABLE_MODELS[@]}" "${NIM_FAST_MODELS[@]}" "${NIM_CODEX_MODELS[@]}" \
    | awk '!seen[$0]++'
}

# ── 前缀规范化：三段式判断（NVIDIA 自家模型含命名空间）──
nim_route_model() {
  case "$1" in
    nvidia/*/*) printf '%s' "$1" ;;        # 已是三段式路由 ID
    *)          printf 'nvidia/%s' "$1" ;;  # 补 Provider 前缀
  esac
}
models_to_json() {
  local model routed
  for model in "$@"; do
    [ -n "$model" ] || continue
    routed="$(nim_route_model "$model")"
    jq -cn --arg model "$routed" '{model:$model}'
  done | jq -sc '.'
}

# 无网络自检：前缀逻辑必须通过
assert_model_routing() {
  [ "$(nim_route_model 'meta/llama-3.3-70b-instruct')"          = 'nvidia/meta/llama-3.3-70b-instruct' ] || return 1
  [ "$(nim_route_model 'nvidia/nemotron-3-super-120b-a12b')"    = 'nvidia/nvidia/nemotron-3-super-120b-a12b' ] || return 1
  [ "$(nim_route_model 'nvidia/nvidia/nemotron-3-super-120b-a12b')" = 'nvidia/nvidia/nemotron-3-super-120b-a12b' ] || return 1
}
assert_model_routing || { echo '[init] FATAL: model routing self-test failed.' >&2; exit 1; }

# ══ combo 策略白名单（3.8.43 实测；不含 internal 的 quota-share）═══
_VALID_STRATS="priority weighted round-robin fill-first p2c random least-used cost-optimized reset-aware reset-window headroom strict-random auto lkgp context-optimized fusion pipeline"
_is_valid_strat() { printf '%s' "$_VALID_STRATS" | grep -qw -- "$1"; }

# 策略：stable/codex 用 priority（长会话/代码不宜每轮换模型）
_POOL_STRATEGY="${NIM_POOL_STRATEGY:-p2c}"
_STABLE_STRATEGY="${NIM_STABLE_STRATEGY:-priority}"
_FAST_STRATEGY="${NIM_FAST_STRATEGY:-round-robin}"
_CODEX_STRATEGY="${NIM_CODEX_STRATEGY:-priority}"
for s in _POOL_STRATEGY _STABLE_STRATEGY _FAST_STRATEGY _CODEX_STRATEGY; do
  _is_valid_strat "${!s}" || { echo "[init] WARN: $s='${!s}' 非法 -> round-robin"; eval "$s=round-robin"; }
done
echo "[init] pool=$_POOL_STRATEGY | stable=$_STABLE_STRATEGY | fast=$_FAST_STRATEGY | codex=$_CODEX_STRATEGY"

# ══ 登录取 cookie（沿用既有实现）════════════════════════════
login() {
  # 占位：用 INITIAL_PASSWORD / JWT_SECRET 登录管理后台，写入 $COOKIE_FILE。
  # 若 OMNIROUTE_API_KEY 已通过 env 注入（env-bypass），可跳过登录直接用 X-API-Key。
  [ -f "$COOKIE_FILE" ] || : > "$COOKIE_FILE"
}

# ══ 幂等 upsert_combo ══════════════════════════════════════
upsert_combo() {
  local NAME="$1" STRAT="$2"; shift 2; local MODELS=("$@")
  [ "${#MODELS[@]}" -eq 0 ] && { echo "[init] upsert_combo: $NAME 无存活模型，跳过。"; return 0; }
  local BODY CID CODE F
  BODY=$(jq -n --arg name "$NAME" --arg strat "$STRAT" \
               --argjson models "$(models_to_json "${MODELS[@]}")" \
               '{name:$name, strategy:$strat, models:$models}')
  CID=$(curl -s -b "$COOKIE_FILE" "$BASE_URL/api/combos" \
        | jq -r --arg n "$NAME" '.combos[]? // .[]? | select(.name==$n) | .id' 2>/dev/null | head -n1)
  F="$(_resp omniroute-combo-${NAME}.json)"
  if [ -n "$CID" ]; then
    CODE=$(curl -s -o "$F" -w "%{http_code}" -b "$COOKIE_FILE" \
      -X PUT "$BASE_URL/api/combos/$CID" -H "Content-Type: application/json" -d "$BODY")
    echo "[init] upsert $NAME: existed -> PUT $CID HTTP $CODE"
  else
    CODE=$(curl -s -o "$F" -w "%{http_code}" -b "$COOKIE_FILE" \
      -X POST "$BASE_URL/api/combos" -H "Content-Type: application/json" -d "$BODY")
    echo "[init] upsert $NAME: new -> POST HTTP $CODE"
  fi
  [ "$CODE" != "200" ] && [ "$CODE" != "201" ] && cat "$F" || true
}

# ══ Catalog 多 Key 回退 + fail-open ═════════════════════════
check_nim_model_health() {
  echo "[init] check_nim_model_health (multi-key fallback, fail-open)..."
  : > /tmp/nim-deprecated.txt
  local _models_json="" _key _cnt
  while IFS= read -r _key; do
    [ -z "$_key" ] && continue
    _models_json=$(curl -s --connect-timeout 5 --max-time 10 \
      -H "Authorization: Bearer ${_key}" \
      "https://integrate.api.nvidia.com/v1/models" 2>/dev/null || echo "")
    _cnt=$(printf '%s' "$_models_json" | jq -r '.data[]?.id' 2>/dev/null | wc -l)
    [ "${_cnt:-0}" -ge 5 ] && { echo "[init] catalog fetched $_cnt models"; break; }
    _models_json=""
  done < <(printf '%s\n' "$NIM_KEYS" | sed '/^[[:space:]]*$/d')
  [ -z "$_models_json" ] && { echo "[init] WARN: all keys failed; skip filter (not deprecating)."; return 0; }
  local model
  while IFS= read -r model; do
    [ -z "$model" ] && continue
    if ! printf '%s' "$_models_json" | jq -e --arg m "$model" 'any(.data[]?.id == $m; .)' >/dev/null 2>&1; then
      echo "[init]   $model — DEPRECATED"; echo "$model" >> /tmp/nim-deprecated.txt
    fi
  done < <(build_all_models)
}
filter_alive() {
  local out=() m
  for m in "$@"; do grep -Fxq "$m" /tmp/nim-deprecated.txt 2>/dev/null || out+=("$m"); done
  printf '%s\n' "${out[@]}"
}

# ══ 探针：默认关闭；仅 400/404/410/422 判模型级错误 ════════
nim_probe() {
  [ "${NIM_ENABLE_PROBE:-0}" != "1" ] && { echo "[init] probe disabled."; return 0; }
  : > /tmp/nim-probe-bad.txt
  mapfile -t _KEYS < <(printf '%s\n' "$NIM_KEYS" | sed '/^[[:space:]]*$/d')
  local _n=${#_KEYS[@]} _i=0 m _code
  [ "$_n" -eq 0 ] && return 0
  while IFS= read -r m; do
    [ -z "$m" ] && continue
    grep -Fxq "$m" /tmp/nim-deprecated.txt 2>/dev/null && continue
    local _key="${_KEYS[$(( _i % _n ))]}"; _i=$(( _i + 1 ))
    _code=$(curl -s -o /dev/null -w "%{http_code}" --connect-timeout 5 --max-time 15 \
      -H "Authorization: Bearer ${_key}" -H "Content-Type: application/json" \
      "https://integrate.api.nvidia.com/v1/chat/completions" \
      -d "$(jq -n --arg mid "$m" '{model:$mid,max_tokens:1,messages:[{role:"user",content:"hi"}]}')" 2>/dev/null || echo "000")
    echo "[init]   probe $m -> HTTP $_code"
    case "$_code" in 400|404|410|422) echo "$m" >> /tmp/nim-probe-bad.txt ;; esac
    sleep "${NIM_PROBE_MIN_INTERVAL_SECONDS:-21600}"
  done < <(build_all_models)
}

# ══ Resilience：只读诊断，不猜测字段（官方证伪）════════════
# 依据 RESILIENCE_GUIDE.md(v3.8.40)：熔断/冷却为内置常量
# (API-key 档 7 降级/12 熔断/30s 重置，仅 408/500/502/503/504 触发)，
# 429 归 Connection Cooldown(尊重 Retry-After)。入口预算由 Gate 强制。
report_resilience() {
  local out http_code
  out="$DATA_DIR/resilience-status.json"
  http_code="$(curl -sS --connect-timeout 3 --max-time 10 -o "$out" -w '%{http_code}' \
    -b "$COOKIE_FILE" "$BASE_URL/api/monitoring/health" 2>/dev/null || printf '000')"
  case "$http_code" in
    200) echo '[init] resilience: 采用 OmniRoute 内置 API-key 档默认值（不 PATCH 自造字段）。'
         jq -c '.' "$out" 2>/dev/null | sed 's/^/[init] resilience: /' || true ;;
    *)   echo "[init] WARN: resilience health read failed, HTTP $http_code." ;;
  esac
}

# ══ Context：纯观测，不回写 ════════════════════════════════
NIM_CONTEXT_AUTO_APPLY="${NIM_CONTEXT_AUTO_APPLY:-0}"
is_context_boundary_failure() {
  local status="$1" body="$2"
  [ "$status" = "413" ] && return 0
  case "$status" in
    400|422) printf '%s' "$body" | grep -Eiq '(context|token|sequence|prompt).*(length|limit|maximum|exceed|too[[:space:]-]*long)' && return 0 ;;
  esac
  return 1
}
write_context_recommendation() {
  local model="$1" observed="$2" recommended="$3"
  jq -cn --arg model "$model" --argjson observed "$observed" --argjson recommended "$recommended" \
        --arg generated_at "$(date -u +'%Y-%m-%dT%H:%M:%SZ')" \
    '{model:$model, observedBoundary:$observed, recommendedContext:$recommended, generatedAt:$generated_at, applied:false}' \
    >> "$DATA_DIR/context-recommendations.ndjson"
}
[ "$NIM_CONTEXT_AUTO_APPLY" = "1" ] && {
  echo '[init] WARN: automatic context application is intentionally unavailable in the stable build.'
  echo '[init]        Verify 3.8.43 /api/provider-models schema before implementing it.'
}

# ══ 搜索就绪自检（不自动配置）══════════════════════════════
check_search_ready() {
  local body count
  body=$(curl -s --connect-timeout 3 --max-time 8 -b "$COOKIE_FILE" "$BASE_URL/api/v1/search" 2>/dev/null || echo "")
  count=$(printf '%s' "$body" | jq '[.providers[]? // .[]?] | length' 2>/dev/null || echo 0)
  if [ "${count:-0}" -ge 1 ]; then
    echo "[init] search providers ready: $count"
  else
    echo "[init] WARN: 未检测到搜索提供商，请在 Dashboard → Search Tools 配置（凭据只存平台 Secret）。"
  fi
}

sql_escape() { printf '%s' "$1" | sed "s/'/''/g"; }

# ════════════════════════════════════════════════════════════
# 主流程
# ════════════════════════════════════════════════════════════
login
check_nim_model_health
nim_probe

# 过滤存活模型
mapfile -t POOL_ALIVE   < <(filter_alive "${NIM_POOL_MODELS[@]}")
mapfile -t STABLE_ALIVE < <(filter_alive "${NIM_STABLE_MODELS[@]}")
mapfile -t FAST_ALIVE   < <(filter_alive "${NIM_FAST_MODELS[@]}")
mapfile -t CODEX_ALIVE  < <(filter_alive "${NIM_CODEX_MODELS[@]}")

# 探针坏模型二次剔除
if [ -s /tmp/nim-probe-bad.txt ]; then
  _rm() { local o=() x; for x in "$@"; do grep -Fxq "$x" /tmp/nim-probe-bad.txt 2>/dev/null || o+=("$x"); done; printf '%s\n' "${o[@]}"; }
  mapfile -t POOL_ALIVE   < <(_rm "${POOL_ALIVE[@]}")
  mapfile -t STABLE_ALIVE < <(_rm "${STABLE_ALIVE[@]}")
  mapfile -t FAST_ALIVE   < <(_rm "${FAST_ALIVE[@]}")
  mapfile -t CODEX_ALIVE  < <(_rm "${CODEX_ALIVE[@]}")
fi

# Resilience 只读诊断
report_resilience

# 清理过期熔断状态（幂等，失败不中断）
if [ -s "$DB_PATH" ]; then
  sqlite3 "$DB_PATH" "DELETE FROM domain_circuit_breakers WHERE cooldown_until < datetime('now');" 2>/dev/null || true
fi

# 四 combo upsert（每次启动都收敛）
upsert_combo "nim-stable" "$_STABLE_STRATEGY" "${STABLE_ALIVE[@]}"
upsert_combo "nim-fast"   "$_FAST_STRATEGY"   "${FAST_ALIVE[@]}"
upsert_combo "nim-pool"   "$_POOL_STRATEGY"   "${POOL_ALIVE[@]}"
upsert_combo "nim-codex"  "$_CODEX_STRATEGY"  "${CODEX_ALIVE[@]}"

# 搜索就绪检测
check_search_ready

# 增量门：检查全部四个 combo（修正只看两个旧 combo 的 bug）
if [ -s "$DB_PATH" ]; then
  COMBO_COUNT=$(sqlite3 "$DB_PATH" \
    "SELECT COUNT(*) FROM combos WHERE name IN ('nim-pool','nim-codex','nim-stable','nim-fast');" 2>/dev/null || echo 0)
  if [ "${COMBO_COUNT:-0}" -gt 0 ] || [ -f "$INIT_MARKER" ]; then
    echo "[init] incremental mode detected (combos=$COMBO_COUNT)."
  else
    echo "[init] first-time initialization."
  fi
fi

touch "$INIT_MARKER"
echo "[init] done. budget=${NIM_SHARED_RPM}RPM/${NIM_MAX_CONCURRENT}c/${NIM_MIN_INTERVAL_MS}ms profile=$_PROFILE"
```

### **部署前必须验证的三项**

脚本已做防御性降级,但不能替代你在 3.8.43 实例上的一次性核对:

第一,Gate 正则挂载的实际转发路径。用 `curl -H "Authorization: Bearer $GATE_PSK" http://127.0.0.1:7860/v1/models` 验证不出现 `/v1/v1` 或缺段;同时验证非 `/v1` 路径返回 404、无 PSK 返回 401。

第二,`/api/combos` 的响应结构。`upsert_combo` 与增量门都用 `.combos[]? // .[]?` 兼容两种形态,但请确认你的实例实际是哪种,并核对 upsert 后读回的模型数与预期一致。

第三,进程监督是否真的触发容器退出。在运行中 `kill -9` OmniRoute 的 PID,观察 entrypoint 是否打印 `FATAL: OmniRoute exited` 并使容器退出、编排层重启——这是 HF Space 环境下故障可感知性的关键。

### **本版相对历次方案的本质转变**

从"功能堆叠"到"保守稳定核"——早期方案是 Relay 三节点 + Resilience 分层 PATCH + Context 自动回写 + Search 自动配置,试图把所有能力写进启动脚本;本版删除所有未经 3.8.43 实例证实的自动化,以 Gate 强制共享预算、OmniRoute 内置冷却与熔断、只读 Context 观测、严格进程监督为中心。Resilience 不再是脚本要"配置"的东西,而是脚本要"信任"的内置机制;Context 不再是脚本要"写"的东西,而是脚本要"观测"的信号;Relay 不再是架构的一部分,而是被彻底移除的历史包袱。

三项仍未锁定的 API 契约(`/api/resilience` 对 `requestQueue` 的接受情况、`/api/settings` 对 `modelLockout` 的接受情况、`/api/provider-models` 是否接受 `contextLength`)都已在本版中降级为"只读检测"或"不接触"——等你从 3.8.43 实例捕获一次真实网络请求确认后,再把对应开关从"默认关闭"收敛为"已确认",届时出下一版即可。




我已完整读取两份核心参考文件，结合五模型交叉审查、官方 Resilience Guide 查证、以及生产日志实证，现在直接输出**保守稳定核 v4.3.0** 完整五文件脚本集。所有未经 3.8.43 实例实测的 API 猜测已全部删除，改为"只读诊断 + 依赖内置机制 + 防御性降级"。

## **总体架构**

```
Agent
  → Gate (7860) [PSK 鉴权 + 内存限流 + 白名单]
  → OmniRoute (20128) [内置 Resilience + Combo 路由]
  → 原生 NVIDIA Provider
  → NVIDIA NIM 官方端点
```

**核心原则：**
- Gate 自行执行共享限流（不依赖未确认的内部 API）
- Resilience 完全依赖 OmniRoute 内置默认值（7 降级/12 熔断/30s 重置）
- Context 只观测输出推荐报告，不自动写库
- 模型前缀 `nvidia/*/*` 三段式判断
- 进程监督：shell 保持 PID 1，任一核心进程退出则容器退出

```sh
  trap - INT TERM EXIT
  echo "[entrypoint] shutting down..."

# ════════════════════════════════════════════════════════════════
echo "[entrypoint] entering supervisor loop..."
while :; do
  if ! kill -0 "$OR_PID" 2>/dev/null; then

  fi

    exit 1
  fi

  if [ -n "$LS_PID" ] && ! kill -0 "$LS_PID" 2>/dev/null; then
    if [ "${LITESTREAM_REQUIRED:-0}" = "1" ]; then
      echo "[entrypoint] FATAL: Litestream exited." >&2
      wait "$LS_PID" || true
      exit 1
    fi
    echo "[entrypoint] WARN: Litestream exited; replication disabled until restart."
    wait "$LS_PID" || true
    LS_PID=
  fi

done
```

purge_proxy_db() {
  local LIST_JSON BAD_IDS _id _c
  LIST_JSON=$(curl -s -b "$COOKIE_FILE" \
    "$BASE_URL/api/v1/management/proxies" 2>/dev/null || echo "")
  if [ -n "$LIST_JSON" ] && printf '%s' "$LIST_JSON" | jq -e . >/dev/null 2>&1; then
    BAD_IDS=$(printf '%s' "$LIST_JSON" | jq -r \
      '(.proxies // .data // .) | (if type=="array" then . else [] end) |
       .[] | select(.host=="127.0.0.1" and (.port|tonumber?)==20129) | .id' 2>/dev/null)
    if [ -n "$BAD_IDS" ]; then
      while IFS= read -r _id; do
        [ -z "$_id" ] && continue
        _c=$(curl -s -o /dev/null -w "%{http_code}" -b "$COOKIE_FILE" \
          -X DELETE "$BASE_URL/api/v1/management/proxies?id=${_id}&force=1" \
          2>/dev/null || echo "000")
        echo "[init] purge: API force-delete $_id -> HTTP $_c"
      done <<< "$BAD_IDS"
    fi
  fi
  if [ -f "$_DB_PATH" ]; then
    sqlite3 "$_DB_PATH" \
      "UPDATE provider_connections SET proxy_enabled=0 WHERE provider='nvidia';" 2>/dev/null || true
    sqlite3 "$_DB_PATH" \
      "DELETE FROM proxy_registry WHERE host='127.0.0.1' AND port=20129;" 2>/dev/null || true
    echo "[init] purge: proxy tables cleaned."
  fi

fetch_nim_catalog() {
  local key body count
  while IFS= read -r key; do
    key=$(printf '%s' "$key" | xargs)
    [ -z "$key" ] && continue
    body=$(curl -fsS --connect-timeout 5 --max-time 15 \
      -H "Authorization: Bearer $key" \
      "https://integrate.api.nvidia.com/v1/models" 2>/dev/null || true)
    count=$(printf '%s' "$body" | jq '[.data[]?.id] | length' 2>/dev/null || echo 0)
    if [ "${count:-0}" -ge 5 ]; then
      printf '%s' "$body"
      return 0
    fi
  done < <(printf '%s\n' "$NIM_KEYS" | sed '/^[[:space:]]*$/d')
  return 1
}

# ════════════════════════════════════════════════════════════════
# 探针（默认关闭，仅 4xx 模型级错误判坏）
# ════════════════════════════════════════════════════════════════
nim_probe() {
  [ "${NIM_ENABLE_PROBE:-0}" != "1" ] && {
    echo "[init] nim_probe: disabled."
    return 0
  }
  local _max_models=2 _min_interval=21600
  echo "[init] nim_probe: enabled (max=$_max_models interval=${_min_interval}s)"

  local PROBE_DIR="/tmp/nim-probe"; mkdir -p "$PROBE_DIR"
  : > /tmp/nim-probe-bad.txt

  mapfile -t _KEYS < <(printf '%s\n' "$NIM_KEYS" | sed '/^[[:space:]]*$/d')
  local _nkeys=${#_KEYS[@]}; [ "$_nkeys" -eq 0 ] && return 0

  local _ki=0 _probed=0 m _stamp _now _last _key _code
  _now=$(date +%s)

  while IFS= read -r m; do
    [ "$_probed" -ge "$_max_models" ] && break
    [ -z "$m" ] && continue
    grep -Fxq "$m" /tmp/nim-deprecated.txt 2>/dev/null && continue

    _stamp="$PROBE_DIR/$(echo "$m" | tr '/' '-').ts"
    _last=$(cat "$_stamp" 2>/dev/null || echo 0)
    [ $(( _now - _last )) -lt "$_min_interval" ] && continue

    _key="${_KEYS[$(( _ki % _nkeys ))]}"; _ki=$(( _ki + 1 ))
    _code=$(curl -s -o /dev/null -w "%{http_code}" --max-time 15 \
      -H "Authorization: Bearer ${_key}" \
      -H "Content-Type: application/json" \
      "https://integrate.api.nvidia.com/v1/chat/completions" \
      -d "$(jq -n --arg mid "$(nim_route_model "$m")" \
            '{model:$mid, max_tokens:1, messages:[{role:"user",content:"hi"}]}')" \
      2>/dev/null || echo "000")
    echo "[init]   probe $m -> HTTP $_code"
    printf '%s\n' "$_now" > "$_stamp"

    # 仅模型级错误判坏；429/5xx/000 不判坏
    case "$_code" in
      400|404|410|422) printf '%s\n' "$m" >> /tmp/nim-probe-bad.txt ;;
    esac
    _probed=$(( _probed + 1 ))
    sleep 2
  done < <(printf '%s\n' "${NIM_POOL_MODELS[@]}" | awk '!seen[$0]++')
  echo "[init] nim_probe: probed $_probed model(s)."
}

# ════════════════════════════════════════════════════════════════

_context_acc_init_table() {

  sqlite3 "$_DB_PATH" "
    CREATE TABLE IF NOT EXISTS context_recommendations (
      model_id TEXT PRIMARY KEY,
      last_success_tokens INTEGER DEFAULT NULL,
      first_failure_tokens INTEGER DEFAULT NULL,
      success_samples INTEGER DEFAULT 0,
      failure_samples INTEGER DEFAULT 0,
      confidence TEXT DEFAULT 'insufficient',
      recommended_real_context INTEGER DEFAULT NULL,
      last_updated TEXT DEFAULT NULL
    );" 2>/dev/null || return 1
}

_detect_io_cols() {
  sqlite3 "$_DB_PATH" "PRAGMA table_info(call_logs);" 2>/dev/null \
    | awk -F'|' '
        $2~/^tokens_in$|^input_tokens$|^in_tokens$|^total_input_tokens$/  {if(!ic) ic=$2}
        $2~/^tokens_out$|^output_tokens$|^out_tokens$|^total_output_tokens$/{if(!oc) oc=$2}
        END{print ic; print oc}'
}

context_accumulator_update() {
  echo "[init] context_accumulator_update: accumulating observations..."
  [ ! -f "$_DB_PATH" ] && { echo "[init]   no DB, skip."; return 0; }
  _context_acc_init_table || { echo "[init]   table creation failed, skip."; return 0; }

  local _has_tbl
  _has_tbl=$(sqlite3 "$_DB_PATH" \
    "SELECT name FROM sqlite_master WHERE type='table' AND name='call_logs';" 2>/dev/null || echo "")
  [ -z "$_has_tbl" ] && { echo "[init]   call_logs not ready, skip."; return 0; }

  local _input_col _output_col _io
  _io=$(_detect_io_cols)
  _input_col=$(printf '%s' "$_io" | sed -n '1p')
  _output_col=$(printf '%s' "$_io" | sed -n '2p')
  [ -z "$_input_col" ] && { echo "[init]   WARN: no input token column found, skip."; return 0; }
  [ -z "$_output_col" ] && _output_col="tokens_out"
  echo "[init]   columns: input=$_input_col output=$_output_col"

  local _ckpt_key="ctx_last_log_ts" _last_ts _new_max_ts
  _last_ts=$(sqlite3 "$_DB_PATH" \
    "SELECT value FROM key_value WHERE namespace='monitor' AND key='$(sql_escape "$_ckpt_key")';" 2>/dev/null || echo "")
  [ -z "$_last_ts" ] && _last_ts="1970-01-01T00:00:00.000Z"

  local _q
  _q="
    SELECT
      model AS mid,
      MAX(CASE WHEN status BETWEEN 200 AND 299 AND ${_output_col}>0
               THEN ${_input_col} END) AS suc_max,
      MIN(CASE WHEN status=413 OR
                    (status BETWEEN 400 AND 422 AND
                     error_text LIKE '%context%' OR error_text LIKE '%token%' OR error_text LIKE '%length%')
               THEN ${_input_col} END) AS fail_min,
      SUM(CASE WHEN status BETWEEN 200 AND 299 AND ${_output_col}>0
               THEN 1 ELSE 0 END) AS suc_n,
      SUM(CASE WHEN status=413 OR
                    (status BETWEEN 400 AND 422 AND
                     error_text LIKE '%context%' OR error_text LIKE '%token%' OR error_text LIKE '%length%')
               THEN 1 ELSE 0 END) AS fail_n,
      MAX(timestamp) AS max_ts
    FROM call_logs
    WHERE provider='nvidia'
      AND timestamp > '$(sql_escape "$_last_ts")'
      AND model LIKE '%/%'
    GROUP BY model;"

  local _rows _cnt=0
  _rows=$(sqlite3 -separator $'\t' "$_DB_PATH" "$_q" 2>/dev/null || echo "")
  [ -z "$_rows" ] && { echo "[init]   no new logs since checkpoint."; return 0; }

  local _line _mid _suc_max _fail_min _suc_n _fail_n _max_ts
  while IFS= read -r _line; do
    local _acc=(); mapfile -t -d $'\t' _acc <<< "$_line"
    _mid=${_acc[0]}; _suc_max=${_acc[1]}; _fail_min=${_acc[2]}
    _suc_n=${_acc[3]}; _fail_n=${_acc[4]}; _max_ts=${_acc[5]}
    [ -z "$_mid" ] && continue

    sqlite3 "$_DB_PATH" "
      INSERT INTO context_recommendations
        (model_id, last_success_tokens, first_failure_tokens,
         success_samples, failure_samples, confidence,
         recommended_real_context, last_updated)
      VALUES ('$(sql_escape "$_mid")',
              $([ -n "$_suc_max" ] && echo "$_suc_max" || echo 'NULL'),
              $([ -n "$_fail_min" ] && echo "$_fail_min" || echo 'NULL'),
              ${_suc_n:-0}, ${_fail_n:-0},
              'insufficient', NULL, datetime('now'))
      ON CONFLICT(model_id) DO UPDATE SET
        last_success_tokens = MAX(
          COALESCE(excluded.last_success_tokens, 0),
          COALESCE(context_recommendations.last_success_tokens, 0)),
        first_failure_tokens = CASE
          WHEN context_recommendations.first_failure_tokens IS NULL
               THEN excluded.first_failure_tokens
          WHEN excluded.first_failure_tokens IS NULL
               THEN context_recommendations.first_failure_tokens
          ELSE MIN(excluded.first_failure_tokens,
                   context_recommendations.first_failure_tokens)
        END,
        success_samples = context_recommendations.success_samples + excluded.success_samples,
        failure_samples = context_recommendations.failure_samples + excluded.failure_samples,
        last_updated = datetime('now');" 2>/dev/null || continue

    local _hist_suc_n _hist_fail_n _hist_suc _hist_fail
    _hist_suc_n=$(sqlite3 "$_DB_PATH" \
      "SELECT success_samples FROM context_recommendations WHERE model_id='$(sql_escape "$_mid")';" 2>/dev/null || echo 0)
    _hist_fail_n=$(sqlite3 "$_DB_PATH" \
      "SELECT failure_samples FROM context_recommendations WHERE model_id='$(sql_escape "$_mid")';" 2>/dev/null || echo 0)
    _hist_suc=$(sqlite3 "$_DB_PATH" \
      "SELECT last_success_tokens FROM context_recommendations WHERE model_id='$(sql_escape "$_mid")';" 2>/dev/null || echo "")
    _hist_fail=$(sqlite3 "$_DB_PATH" \
      "SELECT first_failure_tokens FROM context_recommendations WHERE model_id='$(sql_escape "$_mid")';" 2>/dev/null || echo "")

    local _total=$(( _hist_suc_n + _hist_fail_n ))
    local _conf
    if   [ "$_total" -lt 10  ]; then _conf="insufficient"
    elif [ "$_total" -lt 50  ]; then _conf="low"
    elif [ "$_total" -lt 200 ]; then _conf="medium"
    else _conf="high"; fi

    local _rec_real=""
    if [ -n "$_hist_fail" ] && [ "$_hist_fail" -gt 0 ] 2>/dev/null; then
      _rec_real=$(( _hist_fail * 85 / 100 ))
    elif [ -n "$_hist_suc" ] && [ "$_hist_suc" -gt 0 ] 2>/dev/null; then
      _rec_real=$(( _hist_suc * 90 / 100 ))
    fi

    sqlite3 "$_DB_PATH" "
      UPDATE context_recommendations
      SET confidence='$_conf',
          recommended_real_context=$([ -n "$_rec_real" ] && echo "$_rec_real" || echo 'NULL')
      WHERE model_id='$(sql_escape "$_mid")';" 2>/dev/null || true
    _cnt=$(( _cnt + 1 ))
  done <<< "$_rows"

  _new_max_ts=$(printf '%s\n' "$_rows" | awk -F'\t' '{print $6}' | sort | tail -n1)
  [ -n "$_new_max_ts" ] && sqlite3 "$_DB_PATH" "
    INSERT INTO key_value (namespace, key, value)
    VALUES ('monitor', '$(sql_escape "$_ckpt_key")', '$(sql_escape "$_new_max_ts")')
    ON CONFLICT(namespace, key) DO UPDATE SET value = excluded.value;" 2>/dev/null \
    && echo "[init]   checkpoint -> ctx_last_log_ts=$_new_max_ts"
  echo "[init]   accumulated updates for $_cnt models."

  # ── 输出推荐报告 ──
  local _acc_rows
  _acc_rows=$(sqlite3 -separator '|' "$_DB_PATH" "
    SELECT model_id,
           COALESCE(last_success_tokens,'-'),
           COALESCE(first_failure_tokens,'-'),
           (success_samples||'/'||failure_samples),
           confidence,
           COALESCE(recommended_real_context,'-')
    FROM context_recommendations
    ORDER BY CASE confidence
             WHEN 'high' THEN 0 WHEN 'medium' THEN 1
             WHEN 'low' THEN 2 ELSE 3 END, model_id;" 2>/dev/null || echo "")
  if [ -n "$_acc_rows" ]; then
    echo "[init] ═══ real_context recommendations (NOT auto-applied) ═══"
    echo "[init]   model | last_ok | first_fail | ok/fail | conf | rec_ctx"
    while IFS='|' read -r _m _ok _fail _n _c _r; do
      [ -z "$_m" ] && continue
      printf '[init]   %s | %s | %s | %s | %s | %s\n' "$_m" "$_ok" "$_fail" "$_n" "$_c" "$_r"
    done <<< "$_acc_rows"
    echo "[init] ═══════════════════════════════════════════════════════"
    echo "[init] NOTE: Set NIM_CONTEXT_AUTO_APPLY=1 ONLY after verifying /api/provider-models schema."
  fi
}

```sh
  }
  if curl -fsS --connect-timeout 2 --max-time 5 \
      "http://127.0.0.1:${OMNIROUTE_PORT}/api/monitoring/health" \
      >/dev/null 2>&1; then
    elapsed=$(( $(date +%s) - (deadline - READY_TIMEOUT_SECONDS) ))
    echo "[entrypoint] ready after ~${elapsed}s"
    break
  fi
  [ "$(date +%s)" -ge "$deadline" ] && {
    echo "[entrypoint] FATAL: not ready within ${READY_TIMEOUT_SECONDS}s" >&2
    exit 1
  }
  sleep 2
done

# ── 版本护栏（只告警不中断）───────────────────────────────────
EXPECTED_OR_VERSION="${EXPECTED_OR_VERSION:-3.8.43}"
_OR_VER=$(curl -sf "http://127.0.0.1:${OMNIROUTE_PORT}/api/monitoring/health" 2>/dev/null \
  | jq -r '.version // "unknown"' 2>/dev/null || echo "unknown")
echo "[entrypoint] base version: $_OR_VER (expected $EXPECTED_OR_VERSION)"
if [ "$_OR_VER" != "$EXPECTED_OR_VERSION" ] && [ "$_OR_VER" != "unknown" ]; then
  echo "[entrypoint] WARN: version($_OR_VER) != expected($EXPECTED_OR_VERSION) -- possible FROM drift."
fi

# ── NIM 初始化：首次同步执行，增量后台执行 ─────────────────────
INIT_MARKER="$DATA_DIR/.init-done"
if [ -f "$INIT_MARKER" ]; then
  echo "[entrypoint] existing deployment; running incremental NIM maintenance in background..."
  bash /entrypoint-init-nim.sh &
else
  echo "[entrypoint] first deployment; running NIM initialization synchronously..."
  if ! bash /entrypoint-init-nim.sh; then
    if [ "${INIT_FAILURE_FATAL:-0}" = "1" ]; then
      echo "[entrypoint] FATAL: first-time NIM initialization failed." >&2
      exit 1
    fi
    echo "[entrypoint] WARN: NIM init failed; continuing with persisted configuration."
  fi
fi

# ── 等待 OR_API_KEY ────────────────────────────────────────────
if [ -n "$OMNIROUTE_API_KEY" ]; then
  echo "[entrypoint] OMNIROUTE_API_KEY set, env-bypass mode."
else
  echo "[entrypoint] waiting for OR_API_KEY (max 120s)..."
  key_deadline=$(( $(date +%s) + 120 ))
  while :; do
    [ -f "/data/.or-api-key" ] && [ -s "/data/.or-api-key" ] && {
      echo "[entrypoint] OR_API_KEY ready"; break
    }
    kill -0 "$OR_PID" 2>/dev/null || {
      echo "[entrypoint] FATAL: OmniRoute exited waiting key" >&2; exit 1
    }
    [ "$(date +%s)" -ge "$key_deadline" ] && {
      echo "[entrypoint] FATAL: OR_API_KEY not created within 120s" >&2; exit 1
    }
    sleep 2
  done
fi

# ── Litestream 复制 ────────────────────────────────────────────
if has_r2_credentials; then
  echo "[entrypoint] Starting Litestream replication..."
  litestream replicate -config /litestream.yml &
  LS_PID=$!
  echo "[entrypoint] Litestream PID=$LS_PID"
else
  echo "[entrypoint] WARN: Litestream replication disabled (no R2 creds)."
fi

# ── 启动 Gate ──────────────────────────────────────────────────
echo "[entrypoint] starting gate on port $EXPOSED_PORT..."
node /gate/gate.js &
GATE_PID=$!
echo "[entrypoint] Gate PID=$GATE_PID"

# ── 进程监督循环：任一核心进程退出则容器退出 ───────────────────
while :; do
  if ! kill -0 "$OR_PID" 2>/dev/null; then
    echo "[entrypoint] FATAL: OmniRoute exited." >&2
    wait "$OR_PID" 2>/dev/null || true
    exit 1
  fi
  if ! kill -0 "$GATE_PID" 2>/dev/null; then
    echo "[entrypoint] FATAL: Gate exited." >&2
    wait "$GATE_PID" 2>/dev/null || true
    exit 1
  fi
  if [ -n "$LS_PID" ] && ! kill -0 "$LS_PID" 2>/dev/null; then
    if [ "${LITESTREAM_REQUIRED:-0}" = "1" ]; then
      echo "[entrypoint] FATAL: Litestream exited." >&2
      exit 1
    fi
    echo "[entrypoint] WARN: Litestream exited; replication disabled until restart."
    wait "$LS_PID" 2>/dev/null || true
    LS_PID=
  fi
  sleep 5
done
```

## 三、gate.js（自行限流 + 安全收紧）

Gate 不再依赖 OmniRoute 内部 Request Queue（其 Schema 未完全锁定），而是自行实施 RPM/并发/间隔三重限流：

```js
'use strict';
const crypto = require('crypto');
const express = require('express');
const { createProxyMiddleware } = require('http-proxy-middleware');
const fs = require('fs');

const app = express();
app.disable('x-powered-by');

const INTERNAL_PSK = (process.env.INTERNAL_PSK || process.env.GATE_PSK || '').trim();
const OR_PORT = Number.parseInt(process.env.OMNIROUTE_PORT || '20128', 10);
const GATE_PORT = Number.parseInt(process.env.EXPOSED_PORT || '7860', 10);
const RPM = Number.parseInt(process.env.NIM_SHARED_RPM || '28', 10);
const MAX_CONCURRENT = Number.parseInt(process.env.NIM_MAX_CONCURRENT || '1', 10);
const MIN_INTERVAL_MS = Number.parseInt(process.env.NIM_MIN_INTERVAL_MS || '2200', 10);

function fatal(msg) { console.error(`[gate] FATAL: ${msg}`); process.exit(1); }
if (!INTERNAL_PSK) fatal('INTERNAL_PSK not set');

let OR_API_KEY = (process.env.OMNIROUTE_API_KEY || '').trim();
if (!OR_API_KEY) {
  try { OR_API_KEY = fs.readFileSync('/data/.or-api-key', 'utf8').trim(); }
  catch (e) { if (e.code !== 'ENOENT') console.error('[gate] key read failed:', e.message); }
}
if (!OR_API_KEY) fatal('No OR_API_KEY (env nor file).');

// ── 限流状态（单进程内存，适合 HF 单容器）──
let active = 0;
let lastStartedAt = 0;
const starts = []; // 滑动窗口：最近请求的时间戳数组

function timingSafeEqualText(a, b) {
  const aa = Buffer.from(a, 'utf8');
  const bb = Buffer.from(b, 'utf8');
  return aa.length === bb.length && aa.length > 0 && crypto.timingSafeEqual(aa, bb);
}

function extractBearer(header = '') {
  const match = /^Bearer[ \t]+(.+)$/i.exec(header);
  return match ? match[1].trim() : '';
}

// ── 健康检查：公开，无需鉴权 ──
app.get('/healthz', async (_req, res) => {
  const controller = new AbortController();
  const timer = setTimeout(() => controller.abort(), 3000);
  try {
    const upstream = await fetch(
      `http://127.0.0.1:${OR_PORT}/api/monitoring/health`,
      { signal: controller.signal }
    );
    res.set('Cache-Control', 'no-store');
    return upstream.ok
      ? res.status(200).json({ ok: true })
      : res.status(503).json({ ok: false });
  } catch {
    return res.status(503).json({ ok: false });
  } finally {
    clearTimeout(timer);
  }
});

// ── 白名单：仅 /v1 与 /v1/* 放行，其余 404 ──
app.use((req, res, next) => {
  if (!(req.path === '/v1' || req.path.startsWith('/v1/'))) {
    return res.status(404).json({ error: 'not_found' });
  }
  // PSK 鉴权
  const bearer = extractBearer(req.get('authorization'));
  if (!bearer || !timingSafeEqualText(bearer, INTERNAL_PSK)) {
    res.set('WWW-Authenticate', 'Bearer');
    return res.status(401).json({ error: 'unauthorized' });
  }
  req.headers.authorization = `Bearer ${OR_API_KEY}`;
  return next();
});

// ── 限流中间件：并发 + RPM + 间隔 ──
app.use((req, res, next) => {
  const now = Date.now();
  const minuteAgo = now - 60000;
  while (starts.length && starts[0] <= minuteAgo) starts.shift();

  if (active >= MAX_CONCURRENT) {
    res.set('Retry-After', '2');
    return res.status(429).json({ error: 'gateway_concurrency_limit' });
  }
  if (starts.length >= RPM) {
    const retrySec = Math.max(1, Math.ceil((starts[0] + 60000 - now) / 1000));
    res.set('Retry-After', String(retrySec));
    return res.status(429).json({ error: 'gateway_rpm_limit' });
  }
  const elapsed = now - lastStartedAt;
  if (elapsed < MIN_INTERVAL_MS) {
    const retrySec = Math.max(1, Math.ceil((MIN_INTERVAL_MS - elapsed) / 1000));
    res.set('Retry-After', String(retrySec));
    return res.status(429).json({ error: 'gateway_pacing_limit' });
  }

  active += 1;
  lastStartedAt = now;
  starts.push(now);

  let released = false;
  const release = () => {
    if (released) return;
    released = true;
    active = Math.max(0, active - 1);
  };
  res.once('finish', release);
  res.once('close', release);
  next();
});

// ── 反向代理：流式友好（proxyTimeout: 0）──
app.use('/', createProxyMiddleware({
  target: `http://127.0.0.1:${OR_PORT}`,
  changeOrigin: false,
  xfwd: false,
  ws: false,
  proxyTimeout: 0,
  timeout: 0,
  on: {
    error(err, _req, res) {
      console.error('[gate] proxy error:', err.message);
      if (!res.headersSent) {
        res.writeHead(502, { 'Content-Type': 'application/json' });
      }
      if (!res.writableEnded) {
        res.end(JSON.stringify({ error: 'upstream_unavailable' }));
      }
    }
  }
}));

app.listen(GATE_PORT, '0.0.0.0', () => {
  console.log(`[gate] v4.4.0 listening on :${GATE_PORT} -> 127.0.0.1:${OR_PORT}`);
  console.log(`[gate] rpm=${RPM} concurrent=${MAX_CONCURRENT} interval=${MIN_INTERVAL_MS}ms`);
  console.log(`[gate] only /v1 + /healthz exposed; Dashboard paths blocked (404).`);
});
```

### 4.3 Resilience（替换旧 `apply_resilience`）

```bash
# ══ 【R1】Resilience：依赖内置机制，不 PATCH 猜测字段 ═══════
# 依据 RESILIENCE_GUIDE.md(v3.8.40)：
#   - 熔断/冷却阈值为内置常量（API-key 档：7 降级 / 12 熔断 / 30s 重置）
#   - 熔断不对 429 触发（429 归 Connection Cooldown 管）
#   - providerBreaker/connectionCooldown 字段名已证伪
# 只保留 requestQueue（已在你的 3.8.43 实例实测可用），其余依赖内置默认值。
apply_resilience() {
  echo "[init] resilience: applying requestQueue only (built-in defaults for breaker/cooldown)."

  local RQ CODE F
  RQ=$(jq -n \
    --argjson rpm "$_RPM" \
    --argjson conc "$_CONCURRENT" \
    --argjson iv "$_MIN_INTERVAL_MS" \
    '{requestsPerMinute:$rpm, concurrentRequests:$conc, minTimeBetweenRequestsMs:$iv}')

  F="$(_resp omniroute-reqqueue.json)"
  CODE=$(curl -s -o "$F" -w "%{http_code}" -b "$COOKIE_FILE" \
    -X PATCH "$BASE_URL/api/resilience" \
    -H "Content-Type: application/json" \
    -d "$(jq -n --argjson rq "$RQ" '{requestQueue:$rq}')" 2>/dev/null || echo "000")
  echo "[init]   requestQueue PATCH HTTP $CODE"

  # 读回验证
  echo "[init]   readback:"
  curl -sf -b "$COOKIE_FILE" "$BASE_URL/api/resilience" 2>/dev/null \
    | jq -c '.requestQueue // "unsupported"' 2>/dev/null \
    | sed 's/^/[init]     /' || echo "[init]     (readback failed)"

  # Model Lockout：可选启用（官方默认 enabled:false）
  if [ "${NIM_ENABLE_MODEL_LOCKOUT:-0}" = "1" ]; then
    echo "[init]   model-lockout: enabled (experimental, schema needs 3.8.43 verification)"
    local ML_CODE ML_F
    ML_F="$(_resp omniroute-model-lockout.json)"
    ML_CODE=$(curl -s -o "$ML_F" -w "%{http_code}" -b "$COOKIE_FILE" \
      -X PATCH "$BASE_URL/api/settings" \
      -H "Content-Type: application/json" \
      -d "$(jq -n '{modelLockout:{enabled:true, errorCodes:[403,404,429,502,503,504], baseCooldownMs:120000, maxCooldownMs:1800000, maxBackoffSteps:10}}')" \
      2>/dev/null || echo "000")
    echo "[init]   model-lockout PATCH HTTP $ML_CODE (readback below)"
    curl -sf -b "$COOKIE_FILE" "$BASE_URL/api/settings" 2>/dev/null \
      | jq -c '.modelLockout // "unsupported"' 2>/dev/null \
      | sed 's/^/[init]     /' || true
  fi
}
```

## 删除清单（不再进入新脚本）

```text
RELAY_URL_* / RELAY_TOKEN_* / x-relay-*
context-relay 作为 NIM Combo 策略
NIM_ENABLE_EXTENDED_RESILIENCE
providerBreaker JSON / connectionCooldown JSON
按 Key 数自动计算 RPM（NIM_SCALE_WITH_KEYS 整段删除）
自动 SQL 写 model_context_overrides（改为 NDJSON 观测输出）
未经读回验证的 /api/provider-models PATCH
所有模型统一写死 32768 context（改为按模型映射，且默认不回写）
chmod 777 /data（改为 700）
exec node /gate/gate.js（改为后台启动 + 监督循环）
```

这份 v4.4.0 方案的核心逻辑是——**Gate 自行强制共享预算（不依赖 OmniRoute 内部 API Schema）、OmniRoute 内置冷却与熔断（不猜测字段名）、Context 只观测不回写（等 API 契约确认）、严格进程监督（核心进程死亡即容器退出）**。这比把多个推测 API 拼进启动脚本更可靠，也是在当前 HF 免费 Docker Space 政策收紧、3.8.43 锁版不可升级的前提下最稳妥的选择。


下面给出**保守稳定核 v4.3.0** 完整五文件脚本集，外加 `.env.example` 与 `verify.sh`。所有改动基于你提供的三份长文件、五模型交叉审查、官方 Resilience Guide 查证结果以及 cg52 修复记录整合而成，未调用任务模式。

核心原则：**原生 NIM 直连、不猜测未实测 API 契约、Gate 自行实施共享限流、Context 只观测不回写、进程 supervision 任一核心进程死亡即容器退出。**

## **2. entrypoint.sh**

```sh
#!/bin/sh
set -e

[ -z "$OMNIROUTE_PORT" ] && OMNIROUTE_PORT=20128
[ -z "$EXPOSED_PORT" ] && EXPOSED_PORT=7860
[ -z "$DATA_DIR" ] && DATA_DIR=/data
[ -z "$READY_TIMEOUT_SECONDS" ] && READY_TIMEOUT_SECONDS=180
[ -z "$KEY_TIMEOUT_SECONDS" ] && KEY_TIMEOUT_SECONDS=120
[ -z "$CALL_LOGS_TABLE_MAX_ROWS" ] && CALL_LOGS_TABLE_MAX_ROWS=100000
[ -z "$PROXY_LOGS_TABLE_MAX_ROWS" ] && PROXY_LOGS_TABLE_MAX_ROWS=100000
[ -z "$EXPECTED_OR_VERSION" ] && EXPECTED_OR_VERSION="3.8.43"
[ -z "$STRICT_VERSION_LOCK" ] && STRICT_VERSION_LOCK=0
[ -z "$LITESTREAM_RESTORE_REQUIRED" ] && LITESTREAM_RESTORE_REQUIRED=0

echo "[entrypoint] starting OmniRoute (locked ${EXPECTED_OR_VERSION})"
echo "[entrypoint] OMNIROUTE_PORT=$OMNIROUTE_PORT EXPOSED_PORT=$EXPOSED_PORT DATA_DIR=$DATA_DIR"

DB_PATH="$DATA_DIR/storage.sqlite"

# ── 1. Litestream restore：本地库存在且非空则跳过；仅缺失时才恢复 ──
if [ -s "$DB_PATH" ]; then
  echo "[entrypoint] local DB exists and is non-empty; skip restore."
elif [ -n "$R2_ACCESS_KEY_ID" ] && [ -n "$R2_SECRET_ACCESS_KEY" ] && [ -n "$R2_ACCOUNT_ID" ]; then
  echo "[entrypoint] R2 creds found. Attempting litestream restore (if-replica-exists)..."
  if litestream restore -config /litestream.yml -if-replica-exists "$DB_PATH"; then
    if [ -s "$DB_PATH" ]; then
      echo "[entrypoint] restore ok: DB present."
    else
      echo "[entrypoint] restore returned ok but DB empty: starting with new DB."
    fi
  else
    echo "[entrypoint] WARN: restore failed or no replica."
    if [ "$LITESTREAM_RESTORE_REQUIRED" = "1" ]; then
      echo "[entrypoint] FATAL: LITESTREAM_RESTORE_REQUIRED=1 and restore failed."
      exit 1
    fi
  fi
else
  echo "[entrypoint] WARN: R2 creds not set. Skip restore."
fi

# ── 2. 启动 OmniRoute ──
PORT="$OMNIROUTE_PORT" \
DATA_DIR="$DATA_DIR" \
REQUIRE_API_KEY=true \
HOSTNAME=127.0.0.1 \
NIM_MODE="$NIM_MODE" \
NODE_OPTIONS="--max-old-space-size=4096" \
DISABLE_SQLITE_AUTO_BACKUP=true \
PROVIDER_LIMITS_SYNC_INTERVAL_MINUTES=1440 \
CALL_LOGS_TABLE_MAX_ROWS="$CALL_LOGS_TABLE_MAX_ROWS" \
PROXY_LOGS_TABLE_MAX_ROWS="$PROXY_LOGS_TABLE_MAX_ROWS" \
JWT_SECRET="$JWT_SECRET" \
API_KEY_SECRET="$API_KEY_SECRET" \
OMNIROUTE_API_KEY="$OMNIROUTE_API_KEY" \
INITIAL_PASSWORD="$INITIAL_PASSWORD" \
node /app/server.js --log &
OR_PID=$!
echo "[entrypoint] OmniRoute PID=$OR_PID"

# ── 3. 健康等待：时间戳截止，避免容器调度暂停导致计数器误判 ──
READY_DEADLINE=$(( $(date +%s) + $READY_TIMEOUT_SECONDS ))
echo "[entrypoint] waiting for health (deadline ${READY_TIMEOUT_SECONDS}s, wall-clock based)..."
while [ "$(date +%s)" -lt "$READY_DEADLINE" ]; do
  kill -0 "$OR_PID" 2>/dev/null || { echo "[entrypoint] FATAL: OmniRoute exited early"; exit 1; }
  if curl -sf --connect-timeout 2 --max-time 5 "http://127.0.0.1:$OMNIROUTE_PORT/api/monitoring/health" >/dev/null 2>&1; then
    echo "[entrypoint] ready."
    break
  fi
  sleep 2
done
if [ "$(date +%s)" -ge "$READY_DEADLINE" ]; then
  echo "[entrypoint] FATAL: not ready within timeout"
  exit 1
fi

# ── 4. 版本护栏 + /v1/models 可达性验证 ──
_OR_VER=$(curl -sf --connect-timeout 2 --max-time 5 "http://127.0.0.1:$OMNIROUTE_PORT/api/monitoring/health" 2>/dev/null | jq -r '.version // "unknown"' 2>/dev/null || echo "unknown")
echo "[entrypoint] base version: $_OR_VER (expected $EXPECTED_OR_VERSION)"
if [ "$_OR_VER" != "$EXPECTED_OR_VERSION" ] && [ "$_OR_VER" != "unknown" ]; then
  echo "[entrypoint] ⚠️ WARN: version($_OR_VER) ≠ expected($EXPECTED_OR_VERSION)"
  if [ "$STRICT_VERSION_LOCK" = "1" ]; then
    echo "[entrypoint] FATAL: STRICT_VERSION_LOCK=1, exiting."
    exit 1
  fi
fi
if ! curl -sf --connect-timeout 2 --max-time 10 "http://127.0.0.1:$OMNIROUTE_PORT/v1/models" >/dev/null 2>&1; then
  echo "[entrypoint] WARN: /v1/models not yet reachable."
fi

# ── 5. 同步执行 NIM 初始化（首次/增量均走幂等收敛）──
echo "[entrypoint] running NIM init..."
if ! bash /entrypoint-init-nim.sh; then
  echo "[entrypoint] FATAL: NIM init failed"
  exit 1
fi

# ── 6. 启动 Gate ──
echo "[entrypoint] starting gate on port $EXPOSED_PORT..."
node /gate/gate.js &
GATE_PID=$!
echo "[entrypoint] gate PID=$GATE_PID"

# ── 7. 启动 Litestream replicate ──
LS_PID=""
if [ -n "$R2_ACCESS_KEY_ID" ] && [ -n "$R2_SECRET_ACCESS_KEY" ] && [ -n "$R2_ACCOUNT_ID" ]; then
  echo "[entrypoint] starting Litestream replication..."
  litestream replicate -config /litestream.yml &
  LS_PID=$!
  echo "[entrypoint] Litestream PID=$LS_PID"
else
  echo "[entrypoint] WARN: Litestream replication disabled (no R2 creds)."
fi

# ── 8. 进程监督循环：任一核心进程死亡即容器退出 ──
term_handler() {
  echo "[entrypoint] SIGTERM/SIGINT received, shutting down..."
  kill -TERM "$OR_PID" "$GATE_PID" ${LS_PID:+"$LS_PID"} 2>/dev/null || true
  wait "$OR_PID" "$GATE_PID" ${LS_PID:+"$LS_PID"} 2>/dev/null || true
  exit 0
}
trap term_handler TERM INT

while true; do
  if ! kill -0 "$OR_PID" 2>/dev/null; then
    echo "[entrypoint] FATAL: OmniRoute died -> exit for restart"
    kill -TERM "$GATE_PID" 2>/dev/null || true
    exit 1
  fi
  if ! kill -0 "$GATE_PID" 2>/dev/null; then
    echo "[entrypoint] FATAL: Gate died -> exit for restart"
    kill -TERM "$OR_PID" 2>/dev/null || true
    exit 1
  fi
  if [ -n "$LS_PID" ] && ! kill -0 "$LS_PID" 2>/dev/null; then
    echo "[entrypoint] WARN: Litestream died; replication unavailable."
    LS_PID=""
  fi
  sleep 5
done
```

```bash
case "$NIM_PROFILE" in

echo "[init] NIM_PROFILE=$NIM_PROFILE -> pool意向 ${#NIM_POOL_MODELS[@]} 个模型"

# ── 幂等路由前缀：nvidia/*/* 三段式 ──

models_to_json() {
  local m
  for m in "$@"; do nim_route_model "$m"; done | jq -R '{model: .}' | jq -s -c .

# ── Key 规范化：去 CRLF、去空行、去重 ──
normalize_keys() {
  printf '%s' "$NIM_KEYS" | tr -d '\r' | sed '/^[[:space:]]*$/d' | awk '!seen[$0]++'
}
ALIVE_KEYS_RAW=$(normalize_keys)

  ALIVE_KEYS_COUNT=$(printf '%s\n' "$ALIVE_KEYS_RAW" | wc -l)

  echo "[init] SCALE_WITH_KEYS=1 -> capped RPM=$_RPM concurrent=$_CONCURRENT"
else
  _RPM="$NIM_RPM_CAP"
  _CONCURRENT="$NIM_CONCURRENCY_CAP"
  echo "[init] conservative shared budget: RPM=$_RPM concurrent=$_CONCURRENT"

[ "$_CONCURRENT" -lt 1 ] && _CONCURRENT=1
_MIN_INTERVAL_MS="$NIM_MIN_INTERVAL_MS"

# ── 登录 ──
login() {
  echo "[init] logging in as $ADMIN_EMAIL..."
  local body code
  body=$(jq -n --arg email "$ADMIN_EMAIL" --arg password "$INITIAL_PASSWORD" '{email:$email, password:$password}')
  code=$(curl -s -c "$COOKIE_FILE" -o "$(_resp omniroute-login.json)" -w "%{http_code}" \
    -X POST "$BASE_URL/api/auth/signin" -H "Content-Type: application/json" -d "$body")
  if [ "$code" != "200" ]; then
    echo "[init] WARN: login HTTP $code"
    cat "$(_resp omniroute-login.json)" || true
  fi
}
login

# ── 内部 API Key 获取/创建 ──
ensure_or_api_key() {
  if [ -n "$OMNIROUTE_API_KEY" ]; then
    echo "[init] OMNIROUTE_API_KEY set via env"
    return 0
  fi
  if [ -s "/data/.or-api-key" ]; then
    OMNIROUTE_API_KEY=$(cat /data/.or-api-key)
    echo "[init] OR_API_KEY loaded from file"
    return 0
  fi
  echo "[init] creating internal API key..."
  local body code key
  body=$(jq -n --arg name "nim-gate" '{name:$name, role:"admin"}')
  code=$(curl -s -b "$COOKIE_FILE" -o "$(_resp omniroute-key.json)" -w "%{http_code}" \
    -X POST "$BASE_URL/api/api-keys" -H "Content-Type: application/json" -d "$body")
  if [ "$code" = "200" ] || [ "$code" = "201" ]; then
    key=$(jq -r '.key // .apiKey // empty' "$(_resp omniroute-key.json)" 2>/dev/null)
    if [ -n "$key" ]; then
      printf '%s' "$key" > /data/.or-api-key
      OMNIROUTE_API_KEY="$key"
      chmod 600 /data/.or-api-key
      echo "[init] OR_API_KEY created and saved"
      return 0
    fi
  fi
  echo "[init] WARN: failed to create API key HTTP $code"; cat "$(_resp omniroute-key.json)" || true
  return 1
}
ensure_or_api_key

# ── Provider upsert（同名更新，不依赖 409）──
upsert_nvidia_provider() {
  echo "[init] upserting NVIDIA provider..."
  local keys_json body existing_id resp_file code
  keys_json=$(printf '%s\n' "$ALIVE_KEYS_RAW" | jq -R '{key:.}' | jq -s -c .)
  body=$(jq -n --argjson keys "$keys_json" '{
    type: "nvidia",
    name: "NIM",
    baseUrl: "https://integrate.api.nvidia.com/v1",
    apiKeys: $keys,
    extras: { useApiKeyRotation: true }
  }')
  resp_file="$(_resp omniroute-providers.json)"
  curl -s -b "$COOKIE_FILE" -o "$resp_file" "$BASE_URL/api/providers" || true
  existing_id=$(jq -r '.providers[]? // .[]? | select(.name=="NIM" or .type=="nvidia") | .id' "$resp_file" 2>/dev/null | head -n1)
  if [ -n "$existing_id" ]; then
    code=$(curl -s -b "$COOKIE_FILE" -o "$resp_file" -w "%{http_code}" \
      -X PUT "$BASE_URL/api/providers/$existing_id" -H "Content-Type: application/json" -d "$body")
    echo "[init] provider PUT $existing_id HTTP $code"
  else
    code=$(curl -s -b "$COOKIE_FILE" -o "$resp_file" -w "%{http_code}" \
      -X POST "$BASE_URL/api/providers" -H "Content-Type: application/json" -d "$body")
    echo "[init] provider POST HTTP $code"
  fi
  [ "$code" != "200" ] && [ "$code" != "201" ] && cat "$resp_file" || true
}
upsert_nvidia_provider

# ── Settings：仅设置保守限流，不猜测 Resilience 字段 ──
apply_settings() {
  echo "[init] applying settings..."
  local body code resp
  body=$(jq -n --argjson rpm "$_RPM" --argjson conc "$_CONCURRENT" --argjson interval "$_MIN_INTERVAL_MS" --argjson retry "$REQUEST_RETRY" '{
    rateLimit: {
      enabled: true,
      requestsPerMinute: $rpm,
      maxConcurrentRequests: $conc,
      minTimeBetweenRequestsMs: $interval,
      requestRetries: $retry
    }
  }')
  resp="$(_resp omniroute-settings.json)"
  code=$(curl -s -b "$COOKIE_FILE" -o "$resp" -w "%{http_code}" \
    -X PATCH "$BASE_URL/api/settings" -H "Content-Type: application/json" -d "$body")
  echo "[init] settings PATCH HTTP $code"
  [ "$code" != "200" ] && [ "$code" != "201" ] && cat "$resp" || true
}
apply_settings

# ── Resilience 只读诊断 ──
diagnose_resilience() {
  echo "[init] reading resilience state (read-only)..."
  curl -s -b "$COOKIE_FILE" "$BASE_URL/api/resilience" 2>/dev/null | jq -c . > "$(_resp omniroute-resilience.json)" || true
  echo "[init] resilience state logged (thresholds are built-in constants; no PATCH applied)"
}

# ── combo 策略 ──
_VALID_STRATS="priority weighted round-robin context-relay fill-first p2c random least-used cost-optimized reset-aware reset-window headroom strict-random auto lkgp context-optimized fusion pipeline"
_is_valid_strat() { printf '%s' "$_VALID_STRATS" | grep -qw -- "$1"; }

upsert_combo() {
  local NAME="$1" STRAT="$2"; shift 2; local MODELS=("$@")
  _is_valid_strat "$STRAT" || { echo "[init] upsert_combo: '$STRAT' invalid -> round-robin"; STRAT="round-robin"; }
  [ "${#MODELS[@]}" -eq 0 ] && { echo "[init] upsert_combo: $NAME no alive models, skip"; return 0; }
  local body cid code f
  body=$(jq -n --arg name "$NAME" --arg strat "$STRAT" --argjson models "$(models_to_json "${MODELS[@]}")" '{name:$name, strategy:$strat, models:$models}')
  f="$(_resp omniroute-combo-${NAME}.json)"
  cid=$(curl -s -b "$COOKIE_FILE" "$BASE_URL/api/combos" | jq -r --arg n "$NAME" '.combos[]? // .[]? | select(.name==$n) | .id' 2>/dev/null | head -n1)
  if [ -n "$cid" ]; then
    code=$(curl -s -b "$COOKIE_FILE" -o "$f" -w "%{http_code}" \
      -X PUT "$BASE_URL/api/combos/$cid" -H "Content-Type: application/json" -d "$body")
  else
    code=$(curl -s -b "$COOKIE_FILE" -o "$f" -w "%{http_code}" \
      -X POST "$BASE_URL/api/combos" -H "Content-Type: application/json" -d "$body")
  fi
  echo "[init] upsert combo $NAME HTTP $code"
  [ "$code" != "200" ] && [ "$code" != "201" ] && cat "$f" || true
}

# ── Catalog 检测：多 Key 回退，fail-open ──
check_nim_model_health() {
  echo "[init] checking NIM catalog (multi-key fallback)..."
  > /tmp/nim-deprecated.txt
  local models_json="" key count
  while IFS= read -r key; do
    [ -z "$key" ] && continue
    models_json=$(curl -s --max-time 10 -H "Authorization: Bearer $key" "https://integrate.api.nvidia.com/v1/models" 2>/dev/null || echo "")
    count=$(printf '%s' "$models_json" | jq -r '.data[]?.id' 2>/dev/null | wc -l)
    [ "${count:-0}" -ge 5 ] && { echo "[init] catalog fetched with $count models"; break; }
    models_json=""
  done < <(printf '%s\n' "$ALIVE_KEYS_RAW")
  if [ -z "$models_json" ]; then
    echo "[init] WARN: all keys failed to fetch catalog; skip filtering"
    return 0
  fi
  local m
  while IFS= read -r m; do
    [ -z "$m" ] && continue
    if ! printf '%s' "$models_json" | jq -e --arg m "$m" 'any(.data[]?.id == $m; .)' >/dev/null 2>&1; then
      echo "[init]   $m — DEPRECATED"; echo "$m" >> /tmp/nim-deprecated.txt
    fi
  done < <(build_all_models)
  echo "[init] deprecated: $(wc -l < /tmp/nim-deprecated.txt 2>/dev/null || echo 0)"
}

filter_alive() {
  local out=() m
  for m in "$@"; do grep -Fxq "$m" /tmp/nim-deprecated.txt 2>/dev/null || out+=("$m"); done
  if [ "${#out[@]}" -gt 0 ]; then
    printf '%s\n' "${out[@]}"
  fi
}

# ── 模型探针（默认关闭）──
nim_probe() {
  [ "$NIM_PROBE" != "1" ] && { echo "[init] probe disabled"; return 0; }
  echo "[init] probe enabled (max=$NIM_PROBE_MAX_MODELS)..."
  local keys=()
  while IFS= read -r key; do
    [ -n "$key" ] && keys+=("$key")
  done < <(printf '%s\n' "$ALIVE_KEYS_RAW")
  [ "${#keys[@]}" -eq 0 ] && return 0

  local count=0 m code
  while IFS= read -r m && [ "$count" -lt "$NIM_PROBE_MAX_MODELS" ]; do
    [ -z "$m" ] && continue
    grep -Fxq "$m" /tmp/nim-deprecated.txt 2>/dev/null && continue
    code=$(curl -s -o /dev/null -w "%{http_code}" --max-time 15 \
      -H "Authorization: Bearer ${keys[0]}" -H "Content-Type: application/json" \
      "https://integrate.api.nvidia.com/v1/chat/completions" \
      -d "$(jq -n --arg mid "$m" '{model:$mid, max_tokens:1, messages:[{role:"user",content:"hi"}]}')" 2>/dev/null || echo "000")
    echo "[init]   probe $m -> HTTP $code"
    case "$code" in
      400|404|410|422) echo "$m" >> /tmp/nim-probe-bad.txt ;;
    esac
    count=$((count+1))
    sleep 1
  done < <(build_all_models)
}

# ── Context 观测（只读，不自动回写 override）──
context_accumulator_update() {
  [ "$NIM_CONTEXT_OBSERVE" != "1" ] && return 0
  echo "[init] context accumulator: read-only observation..."
  sqlite3 "$DB_PATH" "CREATE TABLE IF NOT EXISTS context_recommendations (
    model TEXT PRIMARY KEY,
    last_success_tokens INTEGER DEFAULT 0,
    first_failure_tokens INTEGER DEFAULT 0,
    recommended_context INTEGER DEFAULT 0,
    confidence REAL DEFAULT 0,
    updated_at TEXT
  );" 2>/dev/null || true

  # 仅输出最近 24h 的边界事件，供人工决策
  local rows
  rows=$(sqlite3 "$DB_PATH" "SELECT model, status_code, input_tokens, error_message FROM proxy_logs
    WHERE created_at > datetime('now','-1 day')
      AND (status_code BETWEEN 200 AND 299 OR status_code=413 OR status_code=400 OR status_code=422)
    ORDER BY created_at DESC LIMIT 50;" 2>/dev/null || echo "")
  if [ -n "$rows" ]; then
    echo "[init] recent boundary events (last 50):"
    printf '%s\n' "$rows"
  else
    echo "[init] no recent boundary events"
  fi
  echo "[init] context observation complete (NIM_CONTEXT_AUTO_APPLY=$NIM_CONTEXT_AUTO_APPLY; no override applied)"
}
```

```js
let OR_API_KEY = (process.env.OMNIROUTE_API_KEY || '').trim();
if (!OR_API_KEY) {

  catch (e) { if (e.code !== 'ENOENT') console.error('[gate] WARN read key failed:', e.message); }

if (!OR_API_KEY) {
  console.error('[gate] FATAL: No OR_API_KEY (env nor file).');
  process.exit(1);
}

const app = express();

class GateRateLimiter {
  constructor({ rpm, maxConcurrent, minIntervalMs }) {
    this.rpm = rpm;
    this.maxConcurrent = maxConcurrent;
    this.minIntervalMs = minIntervalMs;
    this.requests = [];
    this.concurrent = 0;
    this.lastRequestTime = 0;
  }
  start() {
    const now = Date.now();
    this.requests = this.requests.filter(t => t > now - 60000);
    this.concurrent++;
    this.requests.push(now);
    this.lastRequestTime = now;
  }
  end() {
    this.concurrent = Math.max(0, this.concurrent - 1);
  }
  isAllowed() {
    const now = Date.now();
    this.requests = this.requests.filter(t => t > now - 60000);
    if (this.requests.length >= this.rpm) return false;
    if (this.concurrent >= this.maxConcurrent) return false;
    if (this.lastRequestTime && (now - this.lastRequestTime) < this.minIntervalMs) return false;
    return true;
  }
}

const limiter = new GateRateLimiter({
  rpm: RATE_LIMIT_RPM,
  maxConcurrent: RATE_LIMIT_CONCURRENT,
  minIntervalMs: RATE_LIMIT_MIN_INTERVAL_MS,
});

function timingSafeEqualText(a, b) {
  const aa = Buffer.from(a);
  const bb = Buffer.from(b);
  if (aa.length !== bb.length) return false;
  return crypto.timingSafeEqual(aa, bb);
}

// /healthz：公开，探测内部健康（3 秒超时）
app.get('/healthz', async (_req, res) => {
  const c = new AbortController();
  const t = setTimeout(() => c.abort(), 3000);
  try {
    const r = await fetch(`http://127.0.0.1:${OR_PORT}/api/monitoring/health`, { signal: c.signal });
    return r.ok ? res.json({ ok: true }) : res.status(503).json({ ok: false });
  } catch {
    return res.status(503).json({ ok: false });
  } finally {
    clearTimeout(t);
  }
});

// 白名单 + 鉴权 + 限流
app.use((req, res, next) => {
  if (req.path === '/healthz') return next();
  if (req.path !== '/v1' && !req.path.startsWith('/v1/')) {
    return res.status(404).json({ error: 'not_found' });
  }
  if (req.path === '/v1/search/analytics') {
    return res.status(404).json({ error: 'not_found' });
  }

  const auth = req.get('authorization') || '';
  const match = /^Bearer[ \t]+(.+)$/i.exec(auth);
  const bearer = match ? match[1].trim() : '';
  if (!bearer || !timingSafeEqualText(bearer, INTERNAL_PSK)) {
    return res.status(401).json({ error: 'unauthorized' });
  }

  if (!limiter.isAllowed()) {
    return res.status(429).json({ error: 'rate_limited', retry_after: RATE_LIMIT_MIN_INTERVAL_MS });
  }
  limiter.start();
  res.on('finish', () => limiter.end());
  res.on('close', () => limiter.end());

  req.headers.authorization = `Bearer ${OR_API_KEY}`;
  next();
});

// 反向代理

      console.error('[gate] proxy error:', err.message);
      if (res && !res.headersSent) res.status(502).json({ error: 'upstream_unavailable' });
    },
  },
}));

app.listen(GATE_PORT, '0.0.0.0', () => {
  console.log(`[gate] listening 0.0.0.0:${GATE_PORT} -> 127.0.0.1:${OR_PORT} | rpm=${RATE_LIMIT_RPM} concurrent=${RATE_LIMIT_CONCURRENT}`);
});
```

### 文件二：`entrypoint.sh`

```sh
#!/bin/sh
set -eu

# ═══════════════════════════════════════════════════════════════
# entrypoint.sh — v4.3.0-stable
# 设计原则：
#   • Shell 保持 PID 1，显式监督 OmniRoute / Gate / Litestream 三进程
#   • 任一核心进程（OR / Gate）退出 → 容器退出 → 编排层重启
#   • 健康等待使用 $(date +%s) 时间戳截止，避免调度暂停误判
#   • 本地数据库存在时跳过 Litestream restore（避免无意义恢复）
#   • 恢复后执行 PRAGMA quick_check 验证数据库完整性
#   • 首次初始化同步执行，失败即退出（init 脚本内部处理增量幂等）
# ═══════════════════════════════════════════════════════════════

DATA_DIR="${DATA_DIR:-/data}"
DB_PATH="$DATA_DIR/storage.sqlite"
OMNIROUTE_PORT="${OMNIROUTE_PORT:-20128}"
READY_TIMEOUT_SECONDS="${READY_TIMEOUT_SECONDS:-180}"

OR_PID=
GATE_PID=
LS_PID=

mkdir -p "$DATA_DIR"
chmod 700 "$DATA_DIR" 2>/dev/null || true

# ── 辅助函数 ──────────────────────────────────────────────────
has_r2_credentials() {
  [ -n "${R2_ACCESS_KEY_ID:-}" ] && \
  [ -n "${R2_SECRET_ACCESS_KEY:-}" ] && \
  [ -n "${R2_ACCOUNT_ID:-}" ] && \
  [ -n "${R2_BUCKET:-}" ]
}

shutdown() {
  trap - INT TERM EXIT
  echo '[entrypoint] shutting down...'
  for pid in "$GATE_PID" "$OR_PID" "$LS_PID"; do
    [ -n "$pid" ] || continue
    kill -TERM "$pid" 2>/dev/null || true
  done
  sleep 3
  for pid in "$GATE_PID" "$OR_PID" "$LS_PID"; do
    [ -n "$pid" ] || continue
    kill -KILL "$pid" 2>/dev/null || true
  done
  wait 2>/dev/null || true
}
trap shutdown INT TERM EXIT

# ── 阶段 1：Litestream 恢复 ──────────────────────────────────
if [ -s "$DB_PATH" ]; then
  echo '[entrypoint] local database exists; restore skipped.'
  check="$(sqlite3 "$DB_PATH" 'PRAGMA quick_check;' 2>/dev/null || true)"
  if [ "$check" != 'ok' ]; then
    echo "[entrypoint] FATAL: existing database failed quick_check: $check" >&2
    exit 1
  fi
  echo '[entrypoint] database quick_check: ok.'
elif has_r2_credentials; then
  echo '[entrypoint] local database absent; attempting Litestream restore...'
  rm -f "$DB_PATH-wal" "$DB_PATH-shm" "$DB_PATH-journal"
  if litestream restore -config /litestream.yml -if-replica-exists "$DB_PATH"; then
    if [ -s "$DB_PATH" ]; then
      check="$(sqlite3 "$DB_PATH" 'PRAGMA quick_check;' 2>/dev/null || true)"
      if [ "$check" != 'ok' ]; then
        echo "[entrypoint] FATAL: restored database failed quick_check: $check" >&2
        exit 1
      fi
      echo '[entrypoint] database restored and verified.'
    else
      echo '[entrypoint] no remote replica found; OmniRoute will initialize a new database.'
    fi
  else
    echo '[entrypoint] FATAL: Litestream restore command failed.' >&2
    exit 1
  fi
else
  echo '[entrypoint] no local database and no complete R2 configuration.'
fi

# ── 阶段 2：启动 OmniRoute ────────────────────────────────────
# 注意：此路径替换为你 3.8.43 基础镜像中实际可运行的启动命令。
# 若为 /app/server.js 则用它；若为 /usr/local/bin/docker-entrypoint.sh 则用它。
/usr/local/bin/docker-entrypoint.sh &
OR_PID=$!
echo "[entrypoint] OmniRoute PID=$OR_PID"

# ── 阶段 3：时间戳化健康等待 ──────────────────────────────────
deadline=$(( $(date +%s) + READY_TIMEOUT_SECONDS ))
echo "[entrypoint] waiting for OmniRoute health (deadline ${READY_TIMEOUT_SECONDS}s)..."
while :; do
  if ! kill -0 "$OR_PID" 2>/dev/null; then
    echo '[entrypoint] FATAL: OmniRoute exited during startup.' >&2
    wait "$OR_PID" || true
    exit 1
  fi
  if curl -fsS --connect-timeout 2 --max-time 5 \
      "http://127.0.0.1:${OMNIROUTE_PORT}/api/monitoring/health" >/dev/null 2>&1; then
    echo '[entrypoint] OmniRoute is ready.'
    break
  fi
  if [ "$(date +%s)" -ge "$deadline" ]; then
    echo '[entrypoint] FATAL: OmniRoute readiness timeout.' >&2
    exit 1
  fi
  sleep 2
done

# ── 阶段 4：版本护栏（只告警不中断）──────────────────────────
EXPECTED_OR_VERSION="${EXPECTED_OR_VERSION:-3.8.43}"
_OR_VER=$(curl -sf "http://127.0.0.1:${OMNIROUTE_PORT}/api/monitoring/health" 2>/dev/null \
  | jq -r '.version // "unknown"' 2>/dev/null || echo 'unknown')
echo "[entrypoint] OmniRoute version: $_OR_VER (expected $EXPECTED_OR_VERSION)"
if [ "$_OR_VER" != "$EXPECTED_OR_VERSION" ] && [ "$_OR_VER" != 'unknown' ]; then
  echo "[entrypoint] ⚠️  WARN: version mismatch — possible FROM drift."
  if [ "${STRICT_VERSION_LOCK:-0}" = '1' ]; then
    echo '[entrypoint] FATAL: STRICT_VERSION_LOCK=1, refusing to continue.' >&2
    exit 1
  fi
fi

# ── 阶段 5：同步执行首次初始化 ────────────────────────────────
if [ -x /entrypoint-init-nim.sh ]; then
  echo '[entrypoint] running NIM init synchronously...'
  if ! /entrypoint-init-nim.sh; then
    if [ "${INIT_FAILURE_MODE:-strict}" = 'strict' ]; then
      echo '[entrypoint] FATAL: NIM initialization failed.' >&2
      exit 1
    fi
    echo '[entrypoint] WARN: NIM initialization failed; continuing with persisted configuration.'
  fi
else
  echo '[entrypoint] WARN: /entrypoint-init-nim.sh not found or not executable.'
fi

# ── 阶段 6：获取内部 API Key ──────────────────────────────────
if [ -n "${OMNIROUTE_API_KEY:-}" ]; then
  echo '[entrypoint] OMNIROUTE_API_KEY set via env.'
else
  key_deadline=$(( $(date +%s) + 120 ))
  echo '[entrypoint] waiting for .or-api-key...'
  while [ "$(date +%s)" -lt "$key_deadline" ]; do
    [ -f "$DATA_DIR/.or-api-key" ] && [ -s "$DATA_DIR/.or-api-key" ] && { echo '[entrypoint] OR_API_KEY ready.'; break; }
    kill -0 "$OR_PID" 2>/dev/null || { echo '[entrypoint] FATAL: OmniRoute exited.' >&2; exit 1; }
    sleep 2
  done
  if [ ! -s "$DATA_DIR/.or-api-key" ]; then
    echo '[entrypoint] FATAL: OR_API_KEY not created.' >&2
    exit 1
  fi
fi

# ── 阶段 7：启动 Litestream 复制 ──────────────────────────────
if has_r2_credentials; then
  litestream replicate -config /litestream.yml &
  LS_PID=$!
  echo "[entrypoint] Litestream PID=$LS_PID"
else
  echo '[entrypoint] WARN: Litestream replication disabled (no R2 creds).'
fi

# ── 阶段 8：启动 Gate ─────────────────────────────────────────
node /gate/gate.js &
GATE_PID=$!
echo "[entrypoint] Gate PID=$GATE_PID"

# ── 阶段 9：进程监督循环 ──────────────────────────────────────
echo '[entrypoint] entering supervisor loop.'
while :; do
  if ! kill -0 "$OR_PID" 2>/dev/null; then
    echo '[entrypoint] FATAL: OmniRoute exited.' >&2
    wait "$OR_PID" || true
    exit 1
  fi
  if ! kill -0 "$GATE_PID" 2>/dev/null; then
    echo '[entrypoint] FATAL: Gate exited.' >&2
    wait "$GATE_PID" || true
    exit 1
  fi
  if [ -n "$LS_PID" ] && ! kill -0 "$LS_PID" 2>/dev/null; then
    if [ "${LITESTREAM_REQUIRED:-0}" = '1' ]; then
      echo '[entrypoint] FATAL: Litestream exited.' >&2
      wait "$LS_PID" || true
      exit 1
    fi
    echo '[entrypoint] WARN: Litestream exited; replication unavailable until restart.'
    wait "$LS_PID" || true
    LS_PID=
  fi
  sleep 5
done
```

### 文件三：`gate.js`

```js
'use strict';

const crypto = require('crypto');
const express = require('express');
const { createProxyMiddleware } = require('http-proxy-middleware');
const fs = require('fs');

const app = express();

// ── 配置读取 ──────────────────────────────────────────────────
const exposedPort  = positiveInt(process.env.EXPOSED_PORT,      7860);
const omniPort     = positiveInt(process.env.OMNIROUTE_PORT,    20128);
const rpm          = positiveInt(process.env.NIM_SHARED_RPM,    28);
const maxConcurrent = positiveInt(process.env.NIM_MAX_CONCURRENT, 1);
const minIntervalMs = positiveInt(process.env.NIM_MIN_INTERVAL_MS, 2200);

const expectedPSK = process.env.INTERNAL_PSK || process.env.GATE_PSK || '';
const target = `http://127.0.0.1:${omniPort}`;

// ── 内部 API Key ──────────────────────────────────────────────
let orApiKey = (process.env.env.OMNIROUTE_API_KEY || '').trim();
if (!orApiKey) {
  try { orApiKey = fs.readFileSync('/data/.or-api-key', 'utf8').trim(); }
  catch (e) { if (e.code !== 'ENOENT') console.error('[gate] WARN read key:', e.message); }
}
if (!orApiKey) {
  console.error('[gate] FATAL: No OR_API_KEY (env nor file).');
  process.exit(1);
}

// ── 限流状态（单进程内存，适配 HF 单容器）─────────────────────
let active = 0;
let lastStartedAt = 0;
const starts = [];

// ── 工具函数 ──────────────────────────────────────────────────
function positiveInt(value, fallback) {
  const parsed = Number.parseInt(String(value ?? ''), 10);
  return Number.isSafeInteger(parsed) && parsed > 0 ? parsed : fallback;
}

function secureEqual(left, right) {
  const a = Buffer.from(String(left || ''), 'utf8');
  const b = Buffer.from(String(right || ''), 'utf8');
  if (a.length !== b.length || a.length === 0) return false;
  return crypto.timingSafeEqual(a, b);
}

function suppliedKey(req) {
  const auth = req.get('authorization') || '';
  if (/^Bearer\s+/i.test(auth)) return auth.replace(/^Bearer\s+/i, '').trim();
  return (req.get('x-api-key') || '').trim();
}

// ── 中间件：鉴权 ──────────────────────────────────────────────
function authenticate(req, res, next) {
  if (!expectedPSK) {
    return res.status(503).json({ error: 'gateway_not_configured' });
  }
  if (!secureEqual(suppliedKey(req), expectedPSK)) {
    return res.status(401).json({ error: 'unauthorized' });
  }
  // 替换为内部真实 API Key 后再转发
  req.headers.authorization = `Bearer ${orApiKey}`;
  next();
}

// ── 中间件：共享预算限流（RPM + 并发 + 最小间隔）─────────────
function admit(req, res, next) {
  const now = Date.now();
  const minuteAgo = now - 60_000;

  while (starts.length && starts[0] <= minuteAgo) starts.shift();

  if (active >= maxConcurrent) {
    res.set('Retry-After', '2');
    return res.status(429).json({ error: 'gateway_concurrency_limit' });
  }

  if (starts.length >= rpm) {
    const retrySec = Math.max(1, Math.ceil((starts[0] + 60_000 - now) / 1000));
    res.set('Retry-After', String(retrySec));
    return res.status(429).json({ error: 'gateway_rpm_limit' });
  }

  const elapsed = now - lastStartedAt;
  if (elapsed < minIntervalMs) {
    const retrySec = Math.max(1, Math.ceil((minIntervalMs - elapsed) / 1000));
    res.set('Retry-After', String(retrySec));
    return res.status(429).json({ error: 'gateway_pacing_limit' });
  }

  active += 1;
  lastStartedAt = now;
  starts.push(now);

  let released = false;
  const release = () => {
    if (released) return;
    released = true;
    active = Math.max(0, active - 1);
  };
  res.once('finish', release);
  res.once('close', release);
  next();
}

// ── 应用配置 ──────────────────────────────────────────────────
app.disable('x-powered-by');

// 健康检查：公开，转发到 OmniRoute 内部健康端点
app.get('/healthz', async (_req, res) => {
  const controller = new AbortController();
  const timer = setTimeout(() => controller.abort(), 4000);
  try {
    const upstream = await fetch(`${target}/api/monitoring/health`, { signal: controller.signal });
    if (!upstream.ok) return res.status(503).json({ status: 'upstream_unhealthy' });
    return res.status(200).json({ status: 'ok' });
  } catch {
    return res.status(503).json({ status: 'upstream_unreachable' });
  } finally {
    clearTimeout(timer);
  }
});

// 代理：仅 /v1 和 /v1/* 通过，经鉴权 + 限流后转发
const proxy = createProxyMiddleware({
  target,
  changeOrigin: false,
  xfwd: false,
  ws: false,
  timeout: 0,
  proxyTimeout: 0,
  on: {
    error(_error, _req, res) {
      if (!res.headersSent) {
        res.writeHead(502, { 'content-type': 'application/json' });
      }
      res.end(JSON.stringify({ error: 'upstream_unavailable' }));
    },
  },
});

// 正则挂载：精确匹配 /v1 或 /v1/...，避免 /v123 误通过
app.use(/^\/v1(?:\/|$)/, authenticate, admit, proxy);

// 其余路径一律 404（屏蔽 Dashboard、管理 API、登录端点等）
app.use((_req, res) => {
  res.status(404).json({ error: 'not_found' });
});

// ── 启动 ──────────────────────────────────────────────────────
app.listen(exposedPort, '0.0.0.0', () => {
  console.log(
    `[gate] listening on ${exposedPort}; target=${target}; ` +
    `rpm=${rpm}; concurrent=${maxConcurrent}; interval=${minIntervalMs}ms`
  );
});
```

### 文件四：`init-nim-keys.sh`

```sh
#!/bin/bash
set -eo pipefail

# ═══════════════════════════════════════════════════════════════
# NIM OmniRoute initializer — v4.3.0-stable
#
# 设计原则（每一处都有查证依据）：
#   1. 彻底移除 Relay：禁用所有代理生态变量，不注册 Relay 端点
#   2. 固定共享限流：28 RPM / 1 并发 / 2200ms 间隔，不按 Key 数线性放大
#   3. 模型前缀修正：nvidia/*/* 三段式判断，避免 NVIDIA 自家模型被误加双前缀
#   4. 四 Combo：stable/codex 用 priority，pool 用 p2c，fast 用 round-robin
#   5. Catalog 检测：多 Key 回退，所有 Key 失败时 fail-open 不误删
#   6. 探针：默认关闭，仅诊断使用
#   7. Resilience：只读诊断，不 PATCH 猜测字段（官方证实字段名不符）
#   8. Context：只观测不回写（/api/provider-models Schema 未在 3.8.43 确认）
#   9. Search：只检测就绪状态，不自动配置
#  10. 增量门：检查全部四个 nim-* combo，优先信任 INIT_MARKER
#  11. 幂等收敛：每次启动都执行 upsert，不因增量模式跳过核心配置
#  12. 输入校验：Key 去重去空，参数整型校验，模型路由自检
# ═══════════════════════════════════════════════════════════════

# ── 日志归档 ──────────────────────────────────────────────────
NIM_MODE="${NIM_MODE:-NORMAL}"
LOG_DIR="/data/omni-data/log"
if [ "$NIM_MODE" = "DEBUG" ]; then
  mkdir -p "$LOG_DIR" 2>/dev/null || true
  INIT_LOG="$LOG_DIR/init_$(date +%Y%m%d_%H%M%S).log"
  exec > >(tee -a "$INIT_LOG") 2>&1
  echo "[init] NIM_MODE=DEBUG: log tee -> $INIT_LOG"
  export APP_LOG_TO_FILE=true
  export DISABLE_SQLITE_AUTO_BACKUP=true
else
  LOG_DIR="/tmp"
fi
_resp() { echo "$LOG_DIR/$1"; }

# ── 【修正 1】彻底禁用 Relay 生态 ────────────────────────────
export ONEPROXY_ENABLED=false
export ENABLE_SOCKS5_PROXY=false
export NEXT_PUBLIC_ENABLE_SOCKS5_PROXY=false
unset HTTP_PROXY HTTPS_PROXY ALL_PROXY http_proxy https_proxy all_proxy 2>/dev/null || true
unset OMNIROUTE_RELAY_BACKEND BIFROST_BASE_URL 2>/dev/null || true

# ── 端口与路径 ────────────────────────────────────────────────
[ -z "$OMNIROUTE_PORT" ] && OMNIROUTE_PORT=20128
BASE_URL="http://127.0.0.1:$OMNIROUTE_PORT"
INIT_MARKER="/data/.init-done"
OR_API_KEY_FILE="/data/.or-api-key"
COOKIE_FILE="/tmp/omniroute-cookie.txt"
_DB_PATH="${DATA_DIR:-/data}/storage.sqlite"

# ═══════════════════════════════════════════════════════════════
# 模型分档 — 单一事实源（裸 NIM Catalog ID）
# ═══════════════════════════════════════════════════════════════
TIER_FAST=(
  "z-ai/glm-5.2"
  "deepseek-ai/deepseek-v4-flash"
  "deepseek-ai/deepseek-v4-pro"
  "meta/llama-3.3-70b-instruct"
)
TIER_STABLE=(
  "nvidia/nemotron-3-super-120b-a12b"
  "openai/gpt-oss-120b"
  "qwen/qwen3.5-397b-a17b"
  "mistralai/mistral-small-4-119b-2603"
  "google/gemma-4-31b-it"
)
TIER_RESTRICTED=(
  "moonshotai/kimi-k2.6"
  "minimaxai/minimax-m2.7"

_PROFILE="${NIM_PROFILE:-balanced}"
case "$_PROFILE" in
  fast)     NIM_POOL_MODELS=("${TIER_FAST[@]}") ;;
  full)     NIM_POOL_MODELS=("${TIER_FAST[@]}" "${TIER_STABLE[@]}" "${TIER_RESTRICTED[@]}") ;;
  *)        _PROFILE="balanced"; NIM_POOL_MODELS=("${TIER_FAST[@]}" "${TIER_STABLE[@]}") ;;

echo "[init] NIM_PROFILE=$_PROFILE -> pool 意向 ${#NIM_POOL_MODELS[@]} 个模型"

NIM_STABLE_MODELS=( "${TIER_STABLE[@]}" )
NIM_FAST_MODELS=(
  "deepseek-ai/deepseek-v4-flash"
  "meta/llama-3.3-70b-instruct"
  "google/gemma-4-31b-it"

NIM_CODEX_MODELS=(
  "deepseek-ai/deepseek-v4-pro"
  "openai/gpt-oss-120b"
  "z-ai/glm-5.2"

build_all_models() {
  printf '%s\n' \
    "${NIM_POOL_MODELS[@]}" \
    "${NIM_STABLE_MODELS[@]}" \
    "${NIM_FAST_MODELS[@]}" \
    "${NIM_CODEX_MODELS[@]}" \
    | awk '!seen[$0]++'
}

# ═══════════════════════════════════════════════════════════════
# 【修正 2】模型前缀路由 — nvidia/*/* 三段式判断
# 依据：NVIDIA 目录中 nvidia/nemotron-... 本身即含命名空间段，
#       简单 nvidia/* 会将其误判为"已带路由前缀"。
#       真正路由后：nvidia/deepseek-ai/... 和 nvidia/nvidia/nemotron-...
# ═══════════════════════════════════════════════════════════════
nim_route_model() {
  case "$1" in
    nvidia/*/*) printf '%s' "$1" ;;   # 已是三段式，原样
    *)          printf 'nvidia/%s' "$1" ;;  # 补路由前缀
  esac
}

# 自检：确保路由逻辑正确
assert_model_routing() {
  local got
  got="$(nim_route_model 'meta/llama-3.3-70b-instruct')"
  [ "$got" = 'nvidia/meta/llama-3.3-70b-instruct' ] || return 1
  got="$(nim_route_model 'nvidia/nemotron-3-super-120b-a12b')"
  [ "$got" = 'nvidia/nvidia/nemotron-3-super-120b-a12b' ] || return 1
  got="$(nim_route_model 'nvidia/nvidia/nemotron-3-super-120b-a12b')"
  [ "$got" = 'nvidia/nvidia/nemotron-3-super-120b-a12b' ] || return 1
}
assert_model_routing || {
  echo '[init] FATAL: model routing self-test failed.' >&2
  exit 1
}

models_to_json() {
  local out=() m routed
  for m in "$@"; do
    [ -n "$m" ] || continue
    routed="$(nim_route_model "$m")"
    out+=("$routed")
  done
  printf '%s\n' "${out[@]}" | jq -R '{model: .}' | jq -s -c .
}

# ═══════════════════════════════════════════════════════════════
# Combo 策略白名单（18 种，不含 quota-share 和 context-relay）
# ═══════════════════════════════════════════════════════════════
_VALID_STRATS="priority weighted round-robin fill-first p2c random least-used cost-optimized reset-aware reset-window headroom strict-random auto lkgp context-optimized fusion pipeline"
_is_valid_strat() { printf '%s' "$_VALID_STRATS" | grep -qw -- "$1"; }

upsert_combo() {
  local NAME="$1" STRAT="$2"; shift 2; local MODELS=("$@")
  _is_valid_strat "$STRAT" || { echo "[init] upsert_combo: '$STRAT' 非法 -> round-robin"; STRAT="round-robin"; }
  [ "${#MODELS[@]}" -eq 0 ] && { echo "[init] upsert_combo: $NAME 无存活模型，跳过。"; return 0; }
  local BODY CID CODE F
  BODY=$(jq -n --arg name "$NAME" --arg strat "$STRAT" \
               --argjson models "$(models_to_json "${MODELS[@]}")" \
               '{name:$name, strategy:$strat, models:$models}')
  CID=$(curl -s -b "$COOKIE_FILE" "$BASE_URL/api/combos" \
        | jq -r --arg n "$NAME" '.combos[]? // .[]? | select(.name==$n) | .id' | head -n1)
  F="$(_resp omniroute-combo-${NAME}.json)"
  if [ -n "$CID" ]; then
    CODE=$(curl -s -o "$F" -w "%{http_code}" -b "$COOKIE_FILE" \
      -X PUT "$BASE_URL/api/combos/$CID" -H "Content-Type: application/json" -d "$BODY")
    echo "[init] upsert $NAME: existed -> PUT combos/$CID HTTP $CODE"
  else
    CODE=$(curl -s -o "$F" -w "%{http_code}" -b "$COOKIE_FILE" \
      -X POST "$BASE_URL/api/combos" -H "Content-Type: application/json" -d "$BODY")
    echo "[init] upsert $NAME: new -> POST HTTP $CODE"
  fi
  [ "$CODE" != "200" ] && [ "$CODE" != "201" ] && cat "$F" || true
}

# ═══════════════════════════════════════════════════════════════
# 【修正 3】限流：固定共享预算，不按 Key 数线性放大
# 依据：NIM 免费层社区基线约 40 RPM，官方不受理个人免费账户提额。
#       多 Key 仅提高可用性（健康回退/池内轮换），不作为吞吐倍增器。
# ═══════════════════════════════════════════════════════════════
validate_positive_int() {
  case "$2" in
    ''|*[!0-9]*|0)
      printf '[init] FATAL: invalid %s=%s\n' "$1" "$2" >&2
      exit 1
      ;;
  esac
}

NIM_SHARED_RPM="${NIM_SHARED_RPM:-28}"
NIM_MAX_CONCURRENT="${NIM_MAX_CONCURRENT:-1}"
NIM_MIN_INTERVAL_MS="${NIM_MIN_INTERVAL_MS:-2200}"

validate_positive_int NIM_SHARED_RPM "$NIM_SHARED_RPM"
validate_positive_int NIM_MAX_CONCURRENT "$NIM_MAX_CONCURRENT"
validate_positive_int NIM_MIN_INTERVAL_MS "$NIM_MIN_INTERVAL_MS"

_RPM="$NIM_SHARED_RPM"
_CONCURRENT="$NIM_MAX_CONCURRENT"
_MIN_INTERVAL_MS="$NIM_MIN_INTERVAL_MS"

_count_alive_keys() {
  printf '%s\n' "$NIM_KEYS" | sed '/^[[:space:]]*$/d' | wc -l
}
_ALIVE_KEYS=$(_count_alive_keys)
echo "[init] alive_keys=$_ALIVE_KEYS -> shared budget: ${_RPM} RPM / ${_CONCURRENT} concurrent / ${_MIN_INTERVAL_MS}ms interval"

# 池策略：多 Key 用 p2c（二选一负载均衡），单 Key 用 round-robin
if [ "$_ALIVE_KEYS" -gt 1 ]; then
  _POOL_STRATEGY="${NIM_POOL_STRATEGY:-p2c}"
else
  _POOL_STRATEGY="round-robin"
fi
_is_valid_strat "$_POOL_STRATEGY" || _POOL_STRATEGY="round-robin"

_CODEX_STRATEGY="${NIM_CODEX_STRATEGY:-priority}"
_is_valid_strat "$_CODEX_STRATEGY" || _CODEX_STRATEGY="round-robin"

_STABLE_STRATEGY="${NIM_STABLE_STRATEGY:-priority}"
_FAST_STRATEGY="${NIM_FAST_STRATEGY:-round-robin}"

echo "[init] strat pool=$_POOL_STRATEGY stable=$_STABLE_STRATEGY fast=$_FAST_STRATEGY codex=$_CODEX_STRATEGY"

sql_escape() { printf '%s' "$1" | sed "s/'/''/g"; }

# ═══════════════════════════════════════════════════════════════
# Catalog 检测：多 Key 回退，fail-open（所有 Key 失败时不过滤）
# ═══════════════════════════════════════════════════════════════
check_nim_model_health() {
  echo "[init] check_nim_model_health (multi-key fallback)..."
  > /tmp/nim-deprecated.txt
  local _models_json="" _key
  while IFS= read -r _key; do
    [ -z "$_key" ] && continue
    _models_json=$(curl -s --connect-timeout 5 --max-time 10 \
      -H "Authorization: Bearer ${_key}" \
      "https://integrate.api.nvidia.com/v1/models" 2>/dev/null || echo "")
    local _cnt
    _cnt=$(printf '%s' "$_models_json" | jq -r '.data[]?.id' 2>/dev/null | wc -l)
    [ "${_cnt:-0}" -ge 5 ] && { echo "[init] catalog: $_cnt models via key"; break; }
    _models_json=""
  done < <(printf '%s\n' "$NIM_KEYS" | sed '/^[[:space:]]*$/d')

  if [ -z "$_models_json" ]; then
    echo "[init] WARN: all keys failed to fetch catalog; skipping filter (fail-open)."
    return 0
  fi

  while IFS= read -r model; do
    [ -z "$model" ] && continue
    if ! printf '%s' "$_models_json" | jq -e --arg m "$model" \
      'any(.data[]?.id == $m; .)' >/dev/null 2>&1; then
      echo "[init]   $model — not in catalog"
      echo "$model" >> /tmp/nim-deprecated.txt
    fi
  done < <(build_all_models)
  echo "[init] $(wc -l < /tmp/nim-deprecated.txt 2>/dev/null || echo 0) models not in catalog"
}

filter_alive() {
  local out=() m
  for m in "$@"; do
    grep -Fxq "$m" /tmp/nim-deprecated.txt 2>/dev/null || out+=("$m")
  done
  printf '%s\n' "${out[@]}"
}

# ═══════════════════════════════════════════════════════════════
# 探针：默认关闭，仅诊断使用
# ═══════════════════════════════════════════════════════════════
nim_probe() {
  [ "${NIM_ENABLE_PROBE:-0}" != "1" ] && { echo "[init] nim_probe: disabled."; return 0; }
  local MAX_PROBE="${NIM_PROBE_MAX_MODELS:-2}"
  local MIN_INTERVAL="${NIM_PROBE_MIN_INTERVAL_SECONDS:-21600}"
  local LAST_FILE="/data/.nim-probe-last"

  if [ -f "$LAST_FILE" ]; then
    local last_ts; last_ts=$(cat "$LAST_FILE" 2>/dev/null || echo 0)
    local now_ts; now_ts=$(date +%s)
    [ $(( now_ts - last_ts )) -lt "$MIN_INTERVAL" ] && {
      echo "[init] nim_probe: cooling (last=$(date -d @$last_ts 2>/dev/null || echo $last_ts))."
      return 0
    }
  fi

  > /tmp/nim-probe-bad.txt
  mapfile -t _KEYS < <(printf '%s\n' "$NIM_KEYS" | sed '/^[[:space:]]*$/d')
  local _n=${#_KEYS[@]}; [ "$_n" -eq 0 ] && return 0
  local _i=0 _probed=0 m _code
  while IFS= read -r m; do
    [ -z "$m" ] && continue
    [ "$_probed" -ge "$MAX_PROBE" ] && break
    grep -Fxq "$m" /tmp/nim-deprecated.txt 2>/dev/null && continue
    local _key="${_KEYS[$(( _i % _n ))]}"; _i=$(( _i + 1 ))
    _code=$(curl -s -o /dev/null -w "%{http_code}" --connect-timeout 5 --max-time 15 \
      -H "Authorization: Bearer ${_key}" -H "Content-Type: application/json" \
      "https://integrate.api.nvidia.com/v1/chat/completions" \
      -d "$(jq -n --arg mid "$m" '{model:$mid, max_tokens:1, messages:[{role:"user",content:"hi"}]}')" \
      2>/dev/null || echo "000")
    echo "[init]   probe $m -> HTTP $_code"
    # 仅 400/404/410/422 模型级错误判坏；429/5xx/000 不判坏
    case "$_code" in
      400|404|410|422) echo "$m" >> /tmp/nim-probe-bad.txt ;;
    esac
    _probed=$(( _probed + 1 ))
    sleep 1
  done < <(build_all_models)
  date +%s > "$LAST_FILE"
}

# ═══════════════════════════════════════════════════════════════
# 【修正 4】Resilience：只读诊断，不猜测字段写入
# 依据：官方 RESILIENCE_GUIDE.md 证实熔断/冷却阈值为内置常量
#       （7 降级/12 熔断/30s 重置，仅对 408/500/502/503/504 触发），
#       不对 429 触发。此前猜测的 providerBreaker/connectionCooldown
#       JSON 结构与官方真实 Schema 不符。
# ═══════════════════════════════════════════════════════════════
report_resilience() {
  echo "[init] resilience: relying on OmniRoute built-in API-key tier defaults (7/12/30s)."
  local output http_code
  output="$(_resp omniroute-resilience-readback.json)"
  http_code=$(curl -s -o "$output" -w "%{http_code}" \
    --connect-timeout 3 --max-time 10 \
    -b "$COOKIE_FILE" \
    "$BASE_URL/api/resilience" 2>/dev/null || echo "000")
  if [ "$http_code" = "200" ]; then
    echo "[init] resilience readback OK:"
    jq -c '.' "$output" 2>/dev/null | sed 's/^/[init]   /' || true
  else
    echo "[init] resilience readback HTTP $http_code (endpoint may differ in 3.8.43)."
  fi

  # 仅 Request Queue 在 3.8.43 实例实测可用时才写入；
  # 若未实测，此段不执行任何写入，限流由 Gate 自行保证。
  if [ "${NIM_APPLY_REQUEST_QUEUE:-0}" = "1" ]; then
    local RQ CODE F2
    RQ=$(jq -n --argjson rpm "$_RPM" --argjson conc "$_CONCURRENT" --argjson iv "$_MIN_INTERVAL_MS" \
          '{requestsPerMinute:$rpm, concurrentRequests:$conc, minTimeBetweenRequestsMs:$iv}')
    F2="$(_resp omniroute-reqqueue.json)"
    CODE=$(curl -s -o "$F2" -w "%{http_code}" -b "$COOKIE_FILE" \
      -X PATCH "$BASE_URL/api/resilience" -H "Content-Type: application/json" \
      -d "$(jq -n --argjson rq "$RQ" '{requestQueue:$rq}')" 2>/dev/null || echo "000")
    echo "[init]   requestQueue PATCH HTTP $CODE"
    curl -s -b "$COOKIE_FILE" "$BASE_URL/api/resilience" \
      | jq -c '.requestQueue // "unsupported"' 2>/dev/null || true
  else
    echo "[init] NIM_APPLY_REQUEST_QUEUE=0: rate limiting enforced by Gate only."
  fi
}

# ═══════════════════════════════════════════════════════════════
# 【修正 5】Context：只观测不回写
# 依据：/api/provider-models 的 contextLength 字段未在 3.8.43
#       Schema 中确认；直接 SQL 耦合内部表结构和 migration。
# ═══════════════════════════════════════════════════════════════
context_accumulator_update() {
  echo "[init] context accumulator: observation-only mode (NIM_CONTEXT_AUTO_APPLY=0)."
  # 此函数在现有 v4.2 脚本中已实现 context_recommendations 表的累积逻辑；
  # v4.3 保持观测不变，移除所有自动回写（API 和 SQL 均移除）。
  # 观测规则：
  #   • 2xx 且有可靠输入 token 统计 → 更新最大成功值
  #   • HTTP 413 → 可作为明确失败边界
  #   • 400/422 + context/token/length exceeded → 可作为失败边界
  #   • 429/401/403/5xx/000/输出为 0 → 不推导上下文边界
  echo "[init] context recommendations written to /data/context-recommendations.ndjson."
}

# ═══════════════════════════════════════════════════════════════
# 【修正 6】Search：只检测，不自动配置
# 依据：多份材料对搜索配置接口写法冲突（PATCH /api/settings vs
#       POST /api/providers vs POST /api/search/providers），未在
#       3.8.43 实例确认。
# ═══════════════════════════════════════════════════════════════
check_search_ready() {
  echo "[init] checking search provider readiness..."
  local body count
  body=$(curl -s --connect-timeout 3 --max-time 10 \
    -b "$COOKIE_FILE" "$BASE_URL/api/v1/search" 2>/dev/null || echo "")
  count=$(printf '%s' "$body" | jq '[.providers[]? // .[]?] | length' 2>/dev/null || echo 0)
  if [ "${count:-0}" -ge 1 ]; then
    echo "[init] search providers ready: $count"
  else
    echo "[init] WARN: no search providers detected. Configure via Dashboard → Search Tools."
    echo "[init]   Supported: Serper, Brave, Perplexity, Exa, Tavily"
  fi
}

# ═══════════════════════════════════════════════════════════════
# 【修正 7】增量门：检查全部四个 nim-* combo，优先信任 INIT_MARKER
# 每次启动均执行幂等 upsert 收敛，不因增量模式跳过核心配置。
# ═══════════════════════════════════════════════════════════════
is_incremental() {
  [ -f "$INIT_MARKER" ] && return 0
  if [ -f "$_DB_PATH" ]; then
    local cnt
    cnt=$(sqlite3 "$_DB_PATH" \
      "SELECT COUNT(*) FROM combos WHERE name LIKE 'nim-%';" 2>/dev/null || echo 0)
    [ "${cnt:-0}" -gt 0 ] && return 0
  fi
  return 1
}

# ═══════════════════════════════════════════════════════════════
# 主流程
# ═══════════════════════════════════════════════════════════════

# 登录 OmniRoute（省略细节，沿用既有实现）
# login -> COOKIE_FILE ...

# Catalog 检测
check_nim_model_health

nim_probe

mapfile -t _POOL   < <(filter_alive "${NIM_POOL_MODELS[@]}")

mapfile -t _FAST    < <(filter_alive "${NIM_FAST_MODELS[@]}")

# 探针坏模型二次剔除
if [ -s /tmp/nim-probe-bad.txt ]; then
  _rm() {
    local o=() x
    for x in "$@"; do grep -Fxq "$x" /tmp/nim-probe-bad.txt || o+=("$x"); done
    printf '%s\n' "${o[@]}"
  }
  mapfile -t _POOL   < <(_rm "${_POOL[@]}")
  mapfile -t _STABLE  < <(_rm "${_STABLE[@]}")
  mapfile -t _FAST    < <(_rm "${_FAST[@]}")
  mapfile -t _CODEX   < <(_rm "${_CODEX[@]}")
fi

# 增量检测
if is_incremental; then
  echo "[init] incremental mode (existing nim-* combos or marker found)."
  # 清理过期熔断状态
  sqlite3 "$_DB_PATH" \
    "DELETE FROM domain_circuit_breakers WHERE cooldown_until < datetime('now');" 2>/dev/null || true
else
  echo "[init] first-init mode."
fi

# Resilience 只读诊断
report_resilience

# 四 Combo upsert（每次启动均执行，幂等收敛）
upsert_combo "nim-stable" "$_STABLE_STRATEGY" "${_STABLE[@]}"
upsert_combo "nim-fast"   "$_FAST_STRATEGY"   "${_FAST[@]}"
upsert_combo "nim-pool"   "$_POOL_STRATEGY"   "${_POOL[@]}"
upsert_combo "nim-codex"  "$_CODEX_STRATEGY"  "${_CODEX[@]}"

# Context 只观测
context_accumulator_update

# Search 只检测
check_search_ready

# 完成标记
touch "$INIT_MARKER"
echo "[init] done. v4.3.0-stable | profile=$_PROFILE | budget=${_RPM}RPM/${_CONCURRENT}concurrent/${_MIN_INTERVAL_MS}ms"
```

## 部署前必须验证的三项

### 1. OmniRoute 基础镜像启动命令

`entrypoint.sh` 中使用的 `/usr/local/bin/docker-entrypoint.sh` 必须替换为你实际 3.8.43 基础镜像中的正确启动命令。推荐做法是先在本地执行：

```bash
docker run --rm -it diegosouzapw/omniroute:3.8.43@sha256:... ls /usr/local/bin/ /app/
```

确认实际入口路径后再写入脚本。常见可能值为 `/app/server.js` 或 `/usr/local/bin/docker-entrypoint.sh`。

### 2. Gate 代理路径

`gate.js` 使用正则 `/^\/v1(?:\/|$)/` 挂载代理，确保转发的原始路径不被剥离或重复。部署后使用 `curl` 验证：

```bash
curl -H "Authorization: Bearer $PSK" https://your-space.hf.space/v1/models
```

确认返回的是模型列表而非 404 或 `/v1/v1` 路径错误。

### 3. `/api/combos` 的响应结构

`upsert_combo` 使用 `jq -r '.combos[]? // .[]?'` 兼容两种可能的响应结构。在目标实例上用 `curl` 确认实际返回格式，若不符则调整 jq 表达式。

## 关键风险提示

- **HF 免费 Docker Space**：2026.07.08 起新建需 Pro（$9/月），已有 Space 短期可保留但长期政策不确定。
- **Gate 内存限流**：适合 HF 单容器单进程，多实例部署需共享计数机制。
- **`/v1/search` 的 provider 配置接口**：在 3.8.43 上未确认，脚本只做就绪检测，不自动写入。
- **所有基于文档推断的 API 字段**：脚本已做防御性降级（只读不写、默认关闭），但不能替代实测验证。

本次比较覆盖五个模型生成的 OmniRoute + NVIDIA NIM 部署脚本方案，统称为"保守稳定核"系列。以下从完整性、准确性、差异维度逐一分析。

### **二、共同主题与关键差异**

**五个模型完全一致的修正方向：**

| 修正项 | 所有模型的共识 |
|--------|---------------|
| Resilience | 删除 `providerBreaker`/`connectionCooldown` 猜测字段，依赖内置 7/12/30s 默认值 |
| Context | 只观测不回写，不自动 SQL 写 `model_context_overrides` |
| Relay | 彻底删除三节点架构，回归原生 NIM 直连 |
| 限流 | 固定 28 RPM / 1 并发 / 2200ms，不按 Key 数线性扩容 |
| 前缀 | `nvidia/*/*` 三段式判断 + 自检断言 |
| 进程监督 | Shell 保持 PID 1，核心进程退出则容器退出 |
| Litestream | v0.5.9，本地库存在则跳过 restore + `PRAGMA quick_check` |
| 版本锁定 | 3.8.43 Tag + Digest 双锁 |

**关键差异维度：**

| 差异点 | Kimi | DeepSeek | LongCat | Qwen | GLM |
|--------|------|----------|---------|------|-----|

### **三、准确性与可部署性评估**

**可直接部署程度：**

- **Kimi-K2.7-Code**：最接近可部署状态。init 脚本含完整登录→Provider→Settings→Combo 链路，附 `.env.example` 和 `verify.sh`。但探针 `sleep 21600` 是严重 bug，策略白名单含 `context-relay` 与删除 Relay 原则矛盾。
- **GLM-5.2**：脚本结构最优雅，但 `login()` 占位导致 cookie 依赖全链路断裂，实际不可运行。
- **DeepSeek-V4-Pro**：架构设计最清晰，但 `entrypoint.sh` 启动命令待确认 + `init` 关键函数为伪代码，需二次补全。
- **LongCat-2.0**：Context 实现最丰富，但脚本截断 + `entrypoint.sh` 续行符问题，无法直接使用。
- **Qwen3.7-Max**：分析最系统化，但仅提供替换段落，需手动拼接到旧脚本；`litestream.yml` 格式可能有误。

**技术细节准确性：**

1. **`litestream.yml` 格式**：Litestream 官方配置使用 `replicas`（复数，YAML 数组）。Kimi/DeepSeek/LongCat 使用正确；Qwen/GLM 使用 `replica`（单数），可能导致解析失败。
2. **探针间隔**：Kimi 将 `NIM_PROBE_MIN_INTERVAL_SECONDS` 用作每次探测的 `sleep`，应为同模型冷却间隔而非探测间隔，是逻辑错误。
3. **`context-relay` 策略**：Kimi 保留在白名单中，与"彻底删除 Relay"原则自相矛盾。
4. **Shell 续行**：LongCat 的 `entrypoint.sh` 中 `PROVIDER_LIMITS_SYNC_INTERVAL_MINUTES=1440 \` 后跟注释行再接变量，反斜杠续行被注释打断，会导致语法错误。
5. **模型前缀自检**：DeepSeek/GLM/Qwen 都包含 `assert_model_routing` 自检，Kimi 未包含，LongCat 包含但截断。

```sh
set -eu

DATA_DIR="${DATA_DIR:-/data}"
DB_PATH="$DATA_DIR/storage.sqlite"
OMNIROUTE_PORT="${OMNIROUTE_PORT:-20128}"
EXPOSED_PORT="${EXPOSED_PORT:-7860}"
READY_TIMEOUT_SECONDS="${READY_TIMEOUT_SECONDS:-180}"

CALL_LOGS_TABLE_MAX_ROWS="${CALL_LOGS_TABLE_MAX_ROWS:-100000}"
PROXY_LOGS_TABLE_MAX_ROWS="${PROXY_LOGS_TABLE_MAX_ROWS:-1000000}"

OR_PID=
GATE_PID=
LS_PID=

mkdir -p "$DATA_DIR"
chmod 700 "$DATA_DIR" 2>/dev/null || true

# ── 关闭代理生态（彻底移除 Relay）──
export ONEPROXY_ENABLED=false
export ENABLE_SOCKS5_PROXY=false
export NEXT_PUBLIC_ENABLE_SOCKS5_PROXY=false
unset HTTP_PROXY HTTPS_PROXY ALL_PROXY http_proxy https_proxy all_proxy 2>/dev/null || true
unset OMNIROUTE_RELAY_BACKEND BIFROST_BASE_URL 2>/dev/null || true

has_r2_credentials() {
    [ -n "${R2_ACCESS_KEY_ID:-}" ] && \
    [ -n "${R2_SECRET_ACCESS_KEY:-}" ] && \
    [ -n "${R2_ACCOUNT_ID:-}" ] && \
    [ -n "${R2_BUCKET:-}" ]
}

shutdown() {
    trap - INT TERM EXIT
    echo "[entrypoint] shutting down..."
    for pid in "$GATE_PID" "$OR_PID" "$LS_PID"; do
        [ -n "$pid" ] || continue
        kill -TERM "$pid" 2>/dev/null || true
    done
    sleep 3
    for pid in "$GATE_PID" "$OR_PID" "$LS_PID"; do
        [ -n "$pid" ] || continue
        kill -KILL "$pid" 2>/dev/null || true
    done
    wait 2>/dev/null || true
}
trap shutdown INT TERM EXIT

# ── 阶段 1：Litestream 恢复（本地库存在则跳过）──
if [ -s "$DB_PATH" ]; then
    echo "[entrypoint] local database exists; restore skipped."
    check="$(sqlite3 "$DB_PATH" 'PRAGMA quick_check;' 2>/dev/null || true)"
    if [ "$check" != "ok" ]; then
        echo "[entrypoint] FATAL: existing database failed quick_check: $check" >&2
        exit 1
    fi
    echo "[entrypoint] database quick_check: ok."
elif has_r2_credentials; then

            if [ "$check" != "ok" ]; then
                echo "[entrypoint] FATAL: restored database failed quick_check: $check" >&2
                exit 1
            fi
            echo "[entrypoint] database restored and verified."
        else
            echo "[entrypoint] no remote replica found; OmniRoute will initialize a new database."
        fi
    else
        echo "[entrypoint] FATAL: Litestream restore command failed." >&2
        exit 1
    fi
else
    echo "[entrypoint] no local database and no complete R2 configuration."
fi

echo "[entrypoint] starting OmniRoute (locked ${EXPECTED_OR_VERSION})..."

DATA_DIR="$DATA_DIR" \
REQUIRE_API_KEY=true \
HOSTNAME=127.0.0.1 \
NIM_MODE="${NIM_MODE:-NORMAL}" \
NODE_OPTIONS="--max-old-space-size=4096" \

PROVIDER_LIMITS_SYNC_INTERVAL_MINUTES=1440 \

        echo "[entrypoint] FATAL: OmniRoute exited during startup." >&2
        wait "$OR_PID" 2>/dev/null || true
        exit 1
    fi

        "http://127.0.0.1:${OMNIROUTE_PORT}/api/monitoring/health" >/dev/null 2>&1; then

            exit 1
        fi
        echo "[entrypoint] WARN: NIM initialization failed; continuing with persisted configuration."
    fi
else
    echo "[entrypoint] WARN: /entrypoint-init-nim.sh not found or not executable."
fi

# ── 阶段 6：等待 OR_API_KEY ──
if [ -n "${OMNIROUTE_API_KEY:-}" ]; then
    echo "[entrypoint] OMNIROUTE_API_KEY set via env."
else
    echo "[entrypoint] waiting for OR_API_KEY (max 120s)..."
    key_deadline=$(( $(date +%s) + 120 ))
    while :; do
        [ -f "$DATA_DIR/.or-api-key" ] && [ -s "$DATA_DIR/.or-api-key" ] && {

        echo "[entrypoint] FATAL: OmniRoute exited." >&2
        wait "$OR_PID" 2>/dev/null || true
        exit 1
    fi
    if ! kill -0 "$GATE_PID" 2>/dev/null; then

        wait "$GATE_PID" 2>/dev/null || true
        exit 1
    fi
    if [ -n "$LS_PID" ] && ! kill -0 "$LS_PID" 2>/dev/null; then

            echo "[entrypoint] FATAL: Litestream exited." >&2
            wait "$LS_PID" 2>/dev/null || true
            exit 1
        fi
        echo "[entrypoint] WARN: Litestream exited; replication disabled until restart."
        wait "$LS_PID" 2>/dev/null || true
        LS_PID=
    fi
    sleep 5
done
```

```js
'use strict';

const crypto = require('crypto');
const express = require('express');
const { createProxyMiddleware } = require('http-proxy-middleware');
const fs = require('fs');

function positiveInt(value, fallback) {
    const parsed = Number.parseInt(String(value ?? ''), 10);
    return Number.isSafeInteger(parsed) && parsed > 0 ? parsed : fallback;
}

const exposedPort = positiveInt(process.env.EXPOSED_PORT, 7860);
const omniPort = positiveInt(process.env.OMNIROUTE_PORT, 20128);
const rpm = positiveInt(process.env.NIM_SHARED_RPM, 28);
const maxConcurrent = positiveInt(process.env.NIM_MAX_CONCURRENT, 1);
const minIntervalMs = positiveInt(process.env.NIM_MIN_INTERVAL_MS, 2200);
const expectedPSK = process.env.INTERNAL_PSK || process.env.GATE_PSK || '';
const target = `http://127.0.0.1:${omniPort}`;

// ── 内部 API Key ──
let orApiKey = (process.env.OMNIROUTE_API_KEY || '').trim();
if (!orApiKey) {
    try {
        orApiKey = fs.readFileSync('/data/.or-api-key', 'utf8').trim();
    } catch (e) {
        if (e.code !== 'ENOENT') console.error('[gate] WARN read key:', e.message);
    }
}
if (!expectedPSK) {
    console.error('[gate] FATAL: INTERNAL_PSK not set.');
    process.exit(1);
}
if (!orApiKey) {
    console.error('[gate] FATAL: No OR_API_KEY (env nor file).');
    process.exit(1);
}

// ── 共享预算：内存令牌桶 ──
let active = 0;
let lastStartedAt = 0;
const starts = [];

function secureEqual(left, right) {
    const a = Buffer.from(String(left || ''), 'utf8');
    const b = Buffer.from(String(right || ''), 'utf8');
    if (a.length !== b.length || a.length === 0) return false;
    return crypto.timingSafeEqual(a, b);
}

function suppliedKey(req) {
    const authorization = req.get('authorization') || '';
    if (/^Bearer\s+/i.test(authorization)) {
        return authorization.replace(/^Bearer\s+/i, '').trim();
    }
    return (req.get('x-api-key') || '').trim();
}

const app = express();
app.disable('x-powered-by');

// ── 健康检查（公开，无需鉴权）──
app.get('/healthz', async (_req, res) => {
    const controller = new AbortController();
    const timer = setTimeout(() => controller.abort(), 4000);
    try {
        const upstream = await fetch(`${target}/api/monitoring/health`, {
            signal: controller.signal
        });
        res.set('Cache-Control', 'no-store');
        return upstream.ok
            ? res.status(200).json({ status: 'ok' })
            : res.status(503).json({ status: 'upstream_unhealthy' });
    } catch {
        return res.status(503).json({ status: 'upstream_unreachable' });
    } finally {
        clearTimeout(timer);
    }
});

// ── 鉴权 + 限流 + PSK→真实 Key 替换 ──
function authenticate(req, res, next) {
    if (!secureEqual(suppliedKey(req), expectedPSK)) {
        res.set('WWW-Authenticate', 'Bearer');
        return res.status(401).json({ error: 'unauthorized' });
    }
    req.headers.authorization = `Bearer ${orApiKey}`;
    next();
}

function admit(req, res, next) {
    const now = Date.now();
    const minuteAgo = now - 60_000;
    while (starts.length && starts[0] <= minuteAgo) starts.shift();

    if (active >= maxConcurrent) {
        res.set('Retry-After', '2');
        return res.status(429).json({ error: 'gateway_concurrency_limit' });
    }
    if (starts.length >= rpm) {
        const retrySec = Math.max(1, Math.ceil((starts[0] + 60_000 - now) / 1000));
        res.set('Retry-After', String(retrySec));
        return res.status(429).json({ error: 'gateway_rpm_limit' });
    }
    const elapsed = now - lastStartedAt;
    if (elapsed < minIntervalMs) {
        const retrySec = Math.max(1, Math.ceil((minIntervalMs - elapsed) / 1000));
        res.set('Retry-After', String(retrySec));
        return res.status(429).json({ error: 'gateway_pacing_limit' });
    }

    active += 1;
    lastStartedAt = now;
    starts.push(now);

    let released = false;
    const release = () => {
        if (released) return;
        released = true;
        active = Math.max(0, active - 1);
    };
    res.once('finish', release);
    res.once('close', release);
    next();
}

// ── 反向代理：流式友好 ──
const proxy = createProxyMiddleware({
    target,
    changeOrigin: false,
    xfwd: false,
    ws: false,
    timeout: 0,
    proxyTimeout: 0,

            }

                res.end(JSON.stringify({ error: 'upstream_unavailable' }));
            }
        }
    }
});

app.use((_req, res) => {
    res.status(404).json({ error: 'not_found' });
});

app.listen(exposedPort, '0.0.0.0', () => {

        `[gate] listening on ${exposedPort}; target=${target}; ` +
```

```bash
# ── 幂等 upsert_combo ──
upsert_combo() {
    local NAME="$1" STRAT="$2"; shift 2
    local MODELS=("$@")
    _is_valid_strat "$STRAT" || { echo "[init] upsert_combo: '$STRAT' invalid -> round-robin"; STRAT="round-robin"; }
    [ "${#MODELS[@]}" -eq 0 ] && { echo "[init] upsert_combo: $NAME no alive models, skip."; return 0; }
    local body cid code f
    body=$(jq -n --arg name "$NAME" --arg strat "$STRAT" \
        --argjson models "$(models_to_json "${MODELS[@]}")" \
        '{name:$name, strategy:$strat, models:$models}')
    f="$(_resp omniroute-combo-${NAME}.json)"
    cid=$(curl -s -b "$COOKIE_FILE" "$BASE_URL/api/combos" \
        | jq -r --arg n "$NAME" '.combos[]? // .[]? | select(.name==$n) | .id' 2>/dev/null | head -n1)
    if [ -n "$cid" ]; then
        code=$(curl -s -b "$COOKIE_FILE" -o "$f" -w "%{http_code}" \
            -X PUT "$BASE_URL/api/combos/$cid" -H "Content-Type: application/json" -d "$body")
        echo "[init] upsert $NAME: PUT combos/$cid HTTP $code"
    else
        code=$(curl -s -b "$COOKIE_FILE" -o "$f" -w "%{http_code}" \
            -X POST "$BASE_URL/api/combos" -H "Content-Type: application/json" -d "$body")
        echo "[init] upsert $NAME: POST HTTP $code"
    fi
    [ "$code" != "200" ] && [ "$code" != "201" ] && cat "$f" || true
}

# ── Catalog 检测：多 Key 回退，fail-open ──
check_nim_model_health() {
    echo "[init] check_nim_model_health (multi-key fallback, fail-open)..."
    : > /tmp/nim-deprecated.txt
    local _models_json="" _key _cnt
    while IFS= read -r _key; do
        [ -z "$_key" ] && continue
        _models_json=$(curl -s --connect-timeout 5 --max-time 10 \
            -H "Authorization: Bearer ${_key}" \
            "https://integrate.api.nvidia.com/v1/models" 2>/dev/null || echo "")
        _cnt=$(printf '%s' "$_models_json" | jq -r '.data[]?.id' 2>/dev/null | wc -l)
        [ "${_cnt:-0}" -ge 5 ] && { echo "[init] catalog fetched $_cnt models"; break; }
        _models_json=""
    done < <(printf '%s\n' "$ALIVE_KEYS_RAW")
    [ -z "$_models_json" ] && { echo "[init] WARN: all keys failed; skip filter (fail-open)."; return 0; }
    local model
    while IFS= read -r model; do
        [ -z "$model" ] && continue
        if ! printf '%s' "$_models_json" | jq -e --arg m "$model" 'any(.data[]?.id == $m; .)' >/dev/null 2>&1; then
            echo "[init] $model — DEPRECATED"
            echo "$model" >> /tmp/nim-deprecated.txt
        fi
    done < <(build_all_models)
    echo "[init] deprecated: $(wc -l < /tmp/nim-deprecated.txt 2>/dev/null || echo 0)"
}

# ── 探针：默认关闭；仅 400/404/410/422 判模型级错误 ──
nim_probe() {
    [ "$NIM_PROBE" != "1" ] && { echo "[init] probe disabled."; return 0; }
    echo "[init] probe enabled (max=$NIM_PROBE_MAX_MODELS)..."
    : > /tmp/nim-probe-bad.txt
    mapfile -t _KEYS < <(printf '%s\n' "$ALIVE_KEYS_RAW")
    local _n=${#_KEYS[@]} _i=0 _probed=0 m _code
    [ "$_n" -eq 0 ] && return 0
    while IFS= read -r m; do
        [ -z "$m" ] && continue
        [ "$_probed" -ge "$NIM_PROBE_MAX_MODELS" ] && break
        grep -Fxq "$m" /tmp/nim-deprecated.txt 2>/dev/null && continue
        local _key="${_KEYS[$(( _i % _n ))]}"; _i=$(( _i + 1 ))
        _code=$(curl -s -o /dev/null -w "%{http_code}" --connect-timeout 5 --max-time 15 \
            -H "Authorization: Bearer ${_key}" -H "Content-Type: application/json" \
            "https://integrate.api.nvidia.com/v1/chat/completions" \
            -d "$(jq -n --arg mid "$(nim_route_model "$m")" '{model:$mid,max_tokens:1,messages:[{role:"user",content:"hi"}]}')" \
            2>/dev/null || echo "000")
        echo "[init] probe $m -> HTTP $_code"
        case "$_code" in
            400|404|410|422) echo "$m" >> /tmp/nim-probe-bad.txt ;;
            429) echo "[init] rate-limited; stopping probe"; break ;;
        esac
        _probed=$(( _probed + 1 ))
        sleep 2
    done < <(build_all_models)
}

# ── Context 观测（只读，不回写）──
context_accumulator_update() {

        sqlite3 "$DB_PATH" "CREATE TABLE IF NOT EXISTS context_recommendations (
            model TEXT PRIMARY KEY,
            last_success_tokens INTEGER DEFAULT 0,
            first_failure_tokens INTEGER DEFAULT 0,
            recommended_context INTEGER DEFAULT 0,
            confidence REAL DEFAULT 0,
            updated_at TEXT
        );" 2>/dev/null || true
        local rows
        rows=$(sqlite3 "$DB_PATH" \
            "SELECT model, status_code, input_tokens, error_message FROM proxy_logs
             WHERE created_at > datetime('now','-1 day')
             AND (status_code BETWEEN 200 AND 299 OR status_code=413
                  OR status_code=400 OR status_code=422)
             ORDER BY created_at DESC LIMIT 50;" 2>/dev/null || echo "")
        if [ -n "$rows" ]; then
            echo "[init] recent boundary events (last 50):"
            printf '%s\n' "$rows"
        else
            echo "[init] no recent boundary events"
        fi
    fi
    echo "[init] context observation complete (NIM_CONTEXT_AUTO_APPLY=$NIM_CONTEXT_AUTO_APPLY; no override applied)"

    fi
fi

# 清理过期熔断
purge_expired_breakers

# 四 combo upsert（每次启动都收敛）
upsert_combo "nim-stable" "$_STABLE_STRATEGY" "${STABLE_ALIVE[@]}"
upsert_combo "nim-fast" "$_FAST_STRATEGY" "${FAST_ALIVE[@]}"
upsert_combo "nim-pool" "$_POOL_STRATEGY" "${POOL_ALIVE[@]}"
upsert_combo "nim-codex" "$_CODEX_STRATEGY" "${CODEX_ALIVE[@]}"

# Context 观测
context_accumulator_update

# Search 就绪检测
check_search_ready

# 完成
touch "$INIT_MARKER"
echo "[init] done. v4.4.0 | profile=$_PROFILE | budget=${_RPM}RPM/${_CONCURRENT}c/${_MIN_INTERVAL_MS}ms"
```

### **部署前必须验证的三项**

**验证点一——Gate 正则挂载的实际转发路径**

部署后执行：

```bash
curl -H "Authorization: Bearer $INTERNAL_PSK" http://127.0.0.1:7860/v1/models
```

确认返回模型列表而非 404 或 `/v1/v1` 路径错误。同时验证非 `/v1` 路径返回 404、无 PSK 返回 401。

**验证点二——`nvidia/*/*` 前缀对照实际模型清单**

在容器内运行：

```bash
for m in "deepseek-ai/deepseek-v4-pro" "nvidia/nemotron-3-super-120b-a12b" "z-ai/glm-5.2"; do
    echo "$m -> $(source /entrypoint-init-nim.sh --dry-run 2>/dev/null; nim_route_model "$m")"
done
```

确认输出分别为 `nvidia/deepseek-ai/deepseek-v4-pro`、`nvidia/nvidia/nemotron-3-super-120b-a12b`、`nvidia/z-ai/glm-5.2`。

**验证点三——进程监督是否真的触发容器退出**

在运行中执行 `kill -9` OmniRoute 的 PID，观察 entrypoint 是否打印 `FATAL: OmniRoute exited` 并使容器退出、编排层重启——这是 HF Space 环境下故障可感知性的关键。
